# MD2File 渲染一致性

MD2File 的文件导入、粘贴、手动输入和实时预览统一使用站点共享的 `data/math-renderer.js` 与 `data/markdown-renderer.js`。浏览器固定加载本地 KaTeX `0.16.22`；服务端 DOCX 转换先用同一数学引擎执行阻断校验，再把共享渲染结果转换为 WordprocessingML 和 Office Math。

## 预览与导出门禁

- 每次输入更新都返回 `valid`、`diagnostics` 和定位范围。
- 不完整定界符、未知 LaTeX 或数学引擎不可用时，预览显示安全错误占位，并禁用 DOCX 下载。
- 转换 API 对相同错误返回 `422`，不会生成内容缺失但状态成功的文件。
- 空内容返回 `400`，超过 `512 KB` 返回 `413`，非 DOCX 格式返回 `400`。
- 导入文件必须是可识别的 UTF-8 文本。

## 语义映射

- H1-H6、段落、列表、表格、引用、代码块和分隔线保持原顺序。
- 行内公式、块级公式、根号、复杂分式和上下标转换为 Office Math。
- `\boxed{...}` 转换为紧凑的 `m:borderBox`，不把 `boxed` 当普通文字输出。
- 代码块中的 `$...$` 或 `\frac` 保持代码文本，不参与数学转换。
- 链接在 DOCX 中保留文字和目标地址；图片不执行服务端远程抓取，以可定位的替代文字保留内容位置。

## 页面样式

MD2File 只在自身纸张预览中覆盖共享公式容器：普通 `\[...\]` 无外框和背景，真正的 `\boxed{...}` 只包围公式内容。长公式的横向滚动位于 KaTeX 内容层，纵向尺寸保持自然展开，移动端不会产生公式竖向滚动条。

## 固定回归

`node scripts/test-md2file-docx-semantics.js` 使用同一长文样例对账网页 HTML、DOCX XML 和转换 API，并覆盖无效输入、代码隔离、链接、图片安全回退、中文文件名及 60 节长文。
