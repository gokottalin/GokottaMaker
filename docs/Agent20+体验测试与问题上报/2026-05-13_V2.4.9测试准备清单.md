## P0 必测项

1. 首页头部

- Logo 只显示图标，无外边框，尺寸适中。
- 搜索框、夜间模式按钮、管理端按钮不挤压。
- 1920x1080、1279px 宽度、移动端均不溢出。

2. 首页 Hero

- 轮播只显示 4 个槽位。
- 切换平滑。
- 卡片不应过度模糊，文字清楚可读。
- 点击轮播项能进入对应内容，规划中项目不能暴露完整详情。

3. 管理端 CMS

- 内容蓝图排版整齐。
- 文章/项目切换正常。
- 标题、分类、摘要、标签、发布状态、封面上传、图片库、轮播管理都可操作。
- 轮播排序只允许 0、1、2、3。
- 封面选择按钮样式统一，不应出现原生难看的文件输入框。
- 保存后内容真正写入数据库。

4. 编辑器与 Preview

- 默认左右结构：左侧 Preview，右侧编辑。
- 收起编辑器后，Preview 应扩大。
- Markdown 正文、目录、代码块、长标题、公式降级显示正常。

5. 图片与上传

- 本地上传图片后，管理端能预览。
- 保存后访客端能显示。
- 后续云端测试时，重点确认 `/uploads/` 路径是否可访问。

6. 小程序

- 小程序中心不再显示旧版本号。
- GokottaElec 在线预览为 V1.3。
- MD2File 为 V0.3。
- 夜间模式在小程序页和工具页表现一致。
