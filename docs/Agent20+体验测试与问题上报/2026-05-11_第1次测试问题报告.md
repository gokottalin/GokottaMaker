## BUG-001 / P1 / 详情页非法或未公开 ID 会静默渲染第一条公开内容

代码位置：`D:\Project\26-WEB\GokottaMaker\post.js:240`

复现步骤：

1. 访问 `/post.html?id=not-existing-post`
2. 访问 `/project.html?id=not-existing-project`
3. 访问 `/project.html?id=power-amp`，其中 `power-amp` 是未公开项目

实际结果：

- `/post.html?id=not-existing-post` 渲染为《有源低通滤波器设计与仿真分析》
- `/project.html?id=not-existing-project` 渲染为《GokottaLogic 逻辑分析仪》
- `/project.html?id=power-amp` 也渲染为《GokottaLogic 逻辑分析仪》
- URL 中的 `id` 与页面内容不一致

期望结果：

- `id` 不存在时显示“没有找到内容”或 404 状态
- 未公开项目应显示 `blockedMessage`，不能回退到第一条公开项目

根因定位：

```js
const item = collection.find((entry) => entry.id === id || entry.slug === id) || collection[0];
```

`|| collection[0]` 导致所有非法 ID 都回退到第一条内容。

## BUG-002 / P1 / Markdown 代码高亮会破坏代码块 HTML

代码位置：

- `D:\Project\26-WEB\GokottaMaker\data\markdown-renderer.js:19-23`
- `D:\Project\26-WEB\GokottaMaker\data\markdown-renderer.js:187`
- `D:\Project\26-WEB\GokottaMaker\data\markdown-renderer.js:269`

复现步骤：

1. 在管理端创建文章，正文包含代码块：

````md
```js
const ok = true;
```
````

2. 查看 CMS 预览
3. 保存发布后访问文章详情页

实际结果：

代码块显示为：

```text
"token-keyword">const ok = true;
```

期望结果：

代码块应显示：

```js
const ok = true;
```

根因定位：

`highlight()` 先插入 `<span class="token-keyword">...</span>`，随后字符串正则又匹配插入 HTML 内的 `"token-keyword"`，导致生成的 HTML 被二次替换破坏。
