# 文章公式框选建卡

## 管理员流程

1. 在文章 Markdown 正文中完整框选一个 `$...$`、`$$...$$`、`\\(...\\)` 或 `\\[...\\]` 公式。
2. 打开“文章公式”抽屉并进入“选中公式建卡”。
3. 填写公式名称，从共享分类中选择模块、主分类和多个标签；新分类必须明确点击新增按钮。
4. 点击“保存草稿公式卡并原子绑定”。

保存成功后，公式卡保持草稿状态，原 LaTeX 及其定界符逐字保留，正文仅在公式后追加统一绑定短码。公式卡发布仍使用既有发布门禁。

## 数据约束

- 公式身份由规范化名称和 LaTeX 内容共同生成，得到稳定 `formulaId` 与 `slug`。
- 模块、主分类和标签来自共享 `formula_classifications` 集合，支持检索、复用和显式新建。
- 请求同时携带当前编辑内容的 `sourceHash` 与服务器基线的 `baseSourceHash`。
- 公式卡创建、文章保存、绑定同步和审计记录位于同一事务；任一步失败时全部回滚。
- 已有同身份公式卡不会重复创建，管理员应搜索并绑定已有卡。

## 接口

- `GET /api/admin/formula-classifications`：按类型、父模块和关键词检索共享分类。
- `POST /api/admin/formula-classifications`：显式新建或复用分类。
- `POST /api/admin/formulas/from-selection`：校验完整选区并原子创建草稿公式卡与文章绑定。

## 失败提示

- 选区混入正文、缺少定界符或包含多个公式时，不允许建卡。
- 正文来源哈希或服务器基线哈希变化时，要求刷新并重新框选。
- 模块或主分类未登记时，要求先明确新建。
- 文章处于发布状态时，要求先保存为草稿，再创建和绑定草稿公式卡。
