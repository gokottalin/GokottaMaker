# Agent9 P0 文章内容生成格式与资料配图规范

生成时间：2026-05-10
负责人：Agent9
适用对象：后续负责内容创作的 Agent
适用范围：Agent8 市场部提出的 P0 技术文章、后续同类 STM32 ADC / 模拟前端 / 电路分析文章

## 1. 核心目标

本规范的目标是把文章选题、结构、引用、页码索引、配图要求提前固定。后续内容 Agent 只负责按本规范创作正文，不再重新决定文章格式、引用标准和图片类型。

所有 P0 文章必须满足：

- 文章是工程文章，不是泛教程。
- 文章必须包含真实问题场景、现象、原因、定位、改法、验证。
- 技术事实优先来自第一手资料：芯片数据手册、参考手册、勘误手册、厂商应用笔记、官方评估板手册、官方示例工程、外部器件原厂数据手册。
- 不允许把博客、CSDN、知乎、论坛、B 站、培训课件、二手资料站作为技术事实依据。
- 所有关键资料必须带页码索引。
- 每篇文章必须给出明确配图需求，方便视觉或前端 Agent 接力。

## 2. 默认技术基线

除非任务单另行说明，P0 文章默认使用以下技术基线：

| 项目 | 默认值 | 说明 |
|---|---|---|
| MCU 系列 | STM32G4 | 现有文章已使用类似 `ADC_SAMPLETIME_92CYCLES_5` 的采样时间表达，G4/L4 类 ADC 更匹配 |
| 推荐样例芯片 | STM32G431xB / STM32G431CB | 以 ST `DS12589 Rev 6` 和 `RM0440 Rev 9` 为主 |
| ADC 分辨率 | 12 bit 为主，可补充 10/8/6 bit 对照 | 不允许泛称“STM32 都一样” |
| ADC 时钟示例 | 60 MHz 示例可用，但必须注明来自数据手册条件 | 任何时钟、采样周期、阻抗数字都必须引用 |
| 固件栈 | STM32Cube HAL + 必要时补寄存器说明 | 代码片段要能对应 RM 或 HAL 官方示例 |
| 电路分析对象 | ADC 前端、RC 滤波、输入保护、运放缓冲、参考电压、地回流 | 和 STM32 采样链路强内链 |

如果内容 Agent 改用 STM32F1、STM32F4、STM32H7、ESP32 或其他芯片，必须同时替换数据手册、参考手册、示例代码和页码索引。禁止只替换型号名而沿用 STM32G4 页码。

## 3. 文章交付包

每篇文章必须交付 3 个部分：

1. `article.md`：正文 Markdown。
2. `source-ledger.md`：资料索引表，可放在正文末尾，也可作为附属文件交给发布 Agent。
3. `image-brief.md`：配图需求清单，可放在正文末尾，也可作为附属文件交给视觉 Agent。

如果发布系统只接收一份 Markdown，则把 `source-ledger` 和 `image-brief` 放在正文末尾，使用以下二级标题：

```markdown
## 资料索引

## 配图需求
```

## 4. 正文统一结构

每篇技术文章必须使用以下结构。标题可以微调，但信息顺序不要改。

```markdown
# 文章标题

> 本文适用对象：目标读者、目标芯片/电路、默认测试条件。
> 一句话结论：用 1 句话说明读者看完能解决什么问题。

## 1. 问题现象

- 真实项目里会看到什么现象。
- 现象出现在哪个链路：传感器、电阻分压、RC、运放、ADC、DMA、滤波、地线、电源。
- 给出一个可复现的最小场景。

## 2. 系统链路

用文字和图说明信号从源头到数字结果的路径。

必须覆盖：

- 模拟信号源
- 前端阻容或保护网络
- ADC 输入采样保持
- 参考电压或模拟电源
- DMA/软件处理
- 输出结果或日志

## 3. 原理拆解

解释为什么会发生。

要求：

- 关键公式必须给变量定义。
- 每个数字参数必须有来源引用。
- 不把经验判断写成绝对结论。
- 不跳过边界条件。

## 4. 参数计算或配置推导

把问题转成可计算、可配置、可验证的步骤。

必须包含：

- 输入条件。
- 计算过程。
- 推荐值。
- 推荐值适用边界。
- 如果换芯片或换器件，应该重新查哪张表。

## 5. 电路或代码实现

至少提供一种可执行改法。

STM32 文章必须包含关键代码片段。
电路文章必须包含电路片段或等效模型。

代码要求：

- 只给关键片段，不免费交付完整工程。
- 不出现未经解释的魔法数字。
- 代码注释必须说明和手册寄存器/配置项的对应关系。

## 6. 测试验证

必须告诉读者如何证明改动有效。

优先验证方式：

- 串口采样数据对比。
- 示波器波形。
- 万用表/基准源读数。
- 逻辑分析仪时序。
- DMA 半满/全满回调日志。

必须包含：

- 测试条件。
- 测试步骤。
- 预期现象。
- 失败时下一步排查。

## 7. 常见误区

至少 3 个误区。

格式：

- 误区：一句话说明错误做法。
  正解：说明正确判断方式，并引用资料或验证方式。

## 8. 工程检查清单

给读者一份可复制的检查清单。

每条检查项必须可执行，不写“注意优化”“提高可靠性”这类空话。

## 9. 扩展阅读与内链

至少 3 条站内内链建议。

必须包含：

- 前置知识。
- 后续进阶。
- 相关项目或资料包延展。

## 10. 小结

用 3 到 5 句话总结，不写营销话术。

## 资料索引

按第 6 节规则填写。

## 配图需求

按第 9 节规则填写。
```


- `target_mcu` 必须写具体系列或芯片，不写“STM32 全系列”。

## 6. 资料引用规则

### 6.1 允许使用的资料

| 类型 | 是否可作为核心依据 | 示例 |
|---|---|---|
| 芯片数据手册 Datasheet | 是 | ST `DS12589`、外部运放/TVS/二极管原厂 datasheet |
| 参考手册 Reference Manual | 是 | ST `RM0440` |
| 勘误手册 Errata Sheet | 是 | ST 对应芯片 errata |
| 厂商应用笔记 Application Note | 是 | ST `AN2834`、ST `AN2548` |
| 官方评估板用户手册/原理图 | 是 | ST Nucleo 用户手册、原理图 |
| 官方 SDK/HAL 示例 | 是 | STM32CubeG4 官方 examples |
| 博客/论坛/视频/培训课 | 否 | 只能作为问题线索，不能作为技术依据 |
| AI 生成内容 | 否 | 不能作为资料来源 |
| 电商页/分销商页面 | 否 | 只能用于采购信息，不用于技术参数 |

### 6.2 页码索引格式

每个来源必须同时给出：

- 来源 ID。
- 原厂名称。
- 文档编号。
- 文档标题。
- 修订版本。
- 原厂链接。
- PDF 查看器页码。
- 文档页脚页码。
- 使用位置。

格式：

```markdown
| 来源ID | 原厂 | 文档编号/版本 | 文档标题 | 页码 | 用途 |
|---|---|---|---|---|---|
| S1 | STMicroelectronics | DS12589 Rev 6 | STM32G431x6/x8/xB datasheet | PDF p.118-121 / footer p.119-122 | ADC 电气特性、采样时间、最大 RAIN |
```

页码必须写成 `PDF p.xx / footer p.yy`。如果 PDF 页码和页脚页码一致，也要两者都写。后续修订版本变化时，内容 Agent 必须重新核对页码。

### 6.3 文内引用格式

正文中关键事实必须使用引用标记：

```markdown
STM32G431 的 ADC 采样时间可配置为 2.5 到 640.5 个 ADC 时钟周期，数据手册给出的 60 MHz 条件下采样时间范围为 0.0416 到 10.675 us [S1, PDF p.118 / footer p.119]。
```

必须引用的内容：

- 电气参数。
- 寄存器位含义。
- 采样周期、时钟、最大阻抗、输入电压范围。
- 运放 GBW、压摆率、输出摆幅、负载条件。
- TVS、钳位二极管、电阻、电容的关键参数。
- 官方建议或限制。
- 任何会影响工程决策的数字。

不需要每句都引用，但每个“结论段”至少要能追溯到一个来源。

### 6.4 禁止写法

禁止：

- “网上很多资料都说……”
- “一般来说 STM32 ADC 高阻会不准”但不给出处。
- “建议加一个 100 nF 电容”但不说明位置、原因、边界和来源。
- “轨到轨运放就一定没问题。”
- “模拟地和数字地必须单点连接”但不说明适用场景。
- 只列来源链接，不写页码。
- 只截图手册，不解释手册内容。

## 8. P0 文章清单与内容任务

### P0-1：《STM32 ADC 模拟采样从原理到精度优化》

定位：修复现有文章，作为后续 ADC 知识链入口。

必须写清：

- STM32 ADC 采样链路：模拟源、RC/保护、采样保持、电压参考、ADC 转换、DMA、滤波。
- ADC 误差来源：参考电压、源阻抗、采样时间、输入噪声、注入电流、地回流。
- 采样时间和源阻抗不是“经验调大”，而是和采样保持电容充电有关。
- DMA 环形缓冲只是数据搬运稳定，不会自动提高模拟精度。
- 软件平均只能降低随机噪声，不能修复系统性偏差。

最低资料要求：

- `S-DS12589`：ADC characteristics、Maximum ADC RAIN、ADC 输入等效图。
- `S-RM0440`：ADC conversion mode、ADC timing、data management、sample time registers。
- `S-AN2834`：ADC source resistance、source capacitance、reference voltage、PCB layout、averaging。

正文必须包含：

- 一张完整采样链路图。
- 一个高阻源采样偏低的最小案例。
- 一段 HAL ADC + DMA 关键代码。
- 一个“模拟问题 / 固件问题 / 测量问题”三分法排查表。

### P0-2：《STM32 ADC 采样时间如何影响高阻信号源精度》

定位：讲透高阻源读数偏低，建立 ADC 主线的第一个深水区。

必须写清：

- 高阻源不是“ADC 坏了”，而是采样保持电容在采样窗口内没有充分充电。
- `RAIN`、`RADC`、`CADC`、采样周期、ADC 时钟之间的关系。
- 为什么同样的电压源，低阻输出正常，高阻输出偏低。
- STM32G431 在 60 MHz ADC 时钟下，不同采样周期对应的采样时间和最大 RAIN。
- 延长采样时间、降低分压阻值、增加缓冲、加输入电容分别适合什么场景。

最低资料要求：

- `S-DS12589`：Table 60 ADC characteristics、Table 61 Maximum ADC RAIN。
- `S-RM0440`：ADC_SMPR1/ADC_SMPR2 采样时间寄存器。
- `S-AN2834`：Effect of analog signal source resistance、Workaround for high impedance sources。

正文必须包含：

- 一个 100 k / 100 k 分压测 3.3 V 电池的例子。
- 至少 2 组采样时间对比：短采样偏低，长采样接近真实值。
- 一个计算表：采样周期、采样时间、允许源阻抗、适用场景。

### P0-3：《分压采样为什么不准：源阻抗、漏电流和采样时间》

定位：从硬件工程师最常见的电阻分压切入，把电路误差和 ADC 配置接起来。

必须写清：

- 分压电阻越大，静态功耗越低，但等效源阻抗越高。
- ADC 输入漏电、采样保持、电阻容差、参考电压误差都会影响读数。
- 电池电压检测、传感器输出、保护串联电阻是三个不同场景。
- 分压节点加电容不是万能解，必须说明响应速度和输入稳定时间。
- 高阻分压可以用 GPIO/MOS 控制上电，但要等待节点稳定后再采样。

最低资料要求：

- `S-DS12589`：Maximum ADC RAIN、ADC characteristics、I/O/analog input 限制。
- `S-AN2834`：source resistance、source capacitance、input capacitor、high impedance workaround。
- 外部分压电阻如涉及精度，必须引用电阻原厂 datasheet 或明确写“示例值，不作为器件选型结论”。

正文必须包含：

- 分压等效源阻抗计算。
- 漏电流造成误差的数量级示例。
- 三种改法对比：降低阻值、加电容、加运放缓冲。
- 一个“功耗 / 响应速度 / 精度”取舍表。

### P0-4：《ADC 前端 RC 滤波与输入保护电路设计》

定位：建立 LarkixMaker 的 ADC 前端电路分析主轴。

必须写清：

- ADC 前端不是只放一个电容，而是信号源、限流、滤波、钳位、ADC 输入共同决定。
- RC 截止频率和 ADC 采样瞬态是两件事，不能只按模拟滤波公式选值。
- 串联电阻同时影响限流、源阻抗和采样保持充电。
- 钳位二极管/TVS 要看漏电流和结电容，不是只看“能保护”。
- VREF/VDDA 去耦和模拟地布局会影响最终读数。

最低资料要求：

- `S-DS12589`：ADC 输入等效图、ADC characteristics、Maximum ADC RAIN。
- `S-AN2834`：reference decoupling、source capacitance、injection current、EMI/crosstalk、PCB layout。
- `S-EXT-TVS` 或钳位二极管原厂 datasheet：反向漏电、钳位电压、结电容。

正文必须包含：

- 一个完整前端电路：传感器/输入端、串联电阻、RC、钳位、ADC 引脚、VREF/VDDA 去耦。
- RC 截止频率计算。
- ADC 采样时间检查。
- 输入过压时的限流路径说明。
- “保护更强 / 精度更高 / 响应更快”三者取舍。

### P0-5：《STM32 DMA 环形缓冲：半满/全满回调的正确用法》

定位：补齐 ADC 数据搬运链路，让采样从模拟前端进入可维护固件。

必须写清：

- DMA circular mode 的意义是连续搬运数据，不让 CPU 轮询 ADC。
- 半满/全满回调用于分段处理，避免处理正在被 DMA 写入的区域。
- 数据竞争、缓存一致性、回调耗时、缓冲区长度都会影响结果稳定性。
- ADC 精度问题和 DMA 缓冲问题要分开定位。
- 采样频率、缓冲区大小、处理窗口之间的关系。

最低资料要求：

- `S-RM0440`：DMA functional description、DMA interrupts、DMA_CCRx、DMAMUX、ADC data management。
- `S-AN2548`：DMA/DMAMUX 概念辅助。
- `S-CubeG4`：官方 ADC DMA 示例或 HAL 函数用法。

正文必须包含：

- 一个 256 点 ADC buffer 示例。
- 半满处理前 128 点、全满处理后 128 点的示意。
- 不正确示例：主循环直接扫全 buffer。
- 正确示例：回调中只置标志，主循环处理固定半区。
- 一个采样率和处理时长预算表。

### P0-6：《运放 GBW、压摆率和输出摆幅怎么影响 ADC 采样》

定位：把“ADC 前面加个运放”讲成工程选型问题，而不是口号。

必须写清：

- 运放缓冲可以降低等效源阻抗，但会引入带宽、稳定性、输出摆幅和负载问题。
- GBW 影响闭环带宽和信号建立时间。
- 压摆率影响大信号快速变化时的跟随能力。
- 输出摆幅必须结合 ADC 输入范围、负载、电源电压看。
- 轨到轨不是无限接近电源轨，必须查具体负载条件。
- 运放输出直接驱动 ADC 采样电容时，可能需要小串联电阻隔离。

最低资料要求：

- `S-DS12589`：内部 OPAMP overview 和 OPAMP electrical characteristics。
- `S-AN2834`：采样时间要长于前级放大器传播/建立时间的相关说明。
- `S-EXT-OPAMP`：如使用外部运放，必须提供该运放原厂 datasheet 页码。

正文必须包含：

- 一个传感器输出加运放缓冲再进 ADC 的链路。
- GBW、SR、输出摆幅三个参数各自导致的错误现象。
- 一个“看起来能用但实际不适合”的运放选型反例。
- 一个最小选型检查表。

### P0-7：《模拟地、数字地与 ADC 噪声排查方法》

定位：把 ADC 问题提升到板级系统排查，形成品牌专业感。

必须写清：

- ADC 噪声不只来自 ADC，本质是信号、参考、电源和地回流共同作用。
- 数字 IO 翻转、电源纹波、地回流、参考电压波动都会映射到 ADC code。
- “模拟地/数字地分割”不是绝对规则，必须结合电流回流路径和 PCB 层数。
- 测量地夹位置会影响示波器看到的噪声。
- 先做可重复测量，再谈改板。

最低资料要求：

- `S-AN2834`：I/O crosstalk、EMI-induced noise、shielding、PCB layout、separating analog and digital layouts、star network grounding。
- `S-DS12589`：VDDA/VREF、ADC electrical characteristics。
- 如引用电源芯片或基准源，必须使用原厂 datasheet 页码。

正文必须包含：

- 一个错误布局和一个改进布局对比。
- 一个“示波器地夹位置不同，波形不同”的测试说明。
- 一个排查流程：静态输入短接、稳定基准输入、开关数字负载、观察 VREF/VDDA。
- 一个噪声来源表：现象、可能原因、验证方法、改法。

## 9. 配图总规范

### 9.1 图片类型

每篇文章至少需要 4 类图：

1. 封面图。
2. 系统链路图。
3. 关键电路/时序/等效模型图。
4. 验证图：波形、数据曲线、日志截图或测试表。

### 9.2 文件规格

| 用途 | 推荐尺寸 | 格式 | 背景 | 说明 |
|---|---:|---|---|---|
| 文章封面 | 1600 x 900 | `.webp` + 原始 `.png` | 深浅主题均可读 | 不放大量文字，最多放标题关键词 |
| 正文宽图 | 1400 x 800 | `.png` 或 `.svg` | 浅色为主 | 适合电路、链路、时序 |
| 正文窄图 | 900 x 600 | `.png` 或 `.svg` | 浅色为主 | 适合公式、局部电路 |
| 波形/数据图 | 1200 x 700 | `.png` | 白底或深色仪器风格 | 坐标轴、单位、条件必须清楚 |

图片必须带：

- 文件名。
- 用途。
- 图中元素清单。
- 必须标注的文字。
- 对应正文位置。
- 对应资料来源。
- alt 文本。

禁止：

- 直接搬运手册原图作为配图。
- 把手册截图当正文解释。
- 用过度装饰的抽象图替代工程图。
- 图里出现无法对应正文的器件、参数或引脚。
- 只给“画一个电路图”这类模糊描述。

允许：

- 基于手册等效模型重新绘制简化图，但必须在图注中写“根据 S-xxx 重新绘制，不是原图复刻”。
- 用自测数据生成曲线图。
- 用示波器/逻辑分析仪截图，但必须裁掉无关区域并标注测试条件。
