# Larkix 品牌形象与 LOGO 设计对接

日期：2026-05-18
对接对象：Agent7+视觉品牌与样式设计
来源：LarkixMaker 更名与个人品牌升级讨论
目标：为 Agent7 后续 LOGO、品牌色、图标系统、站点视觉改版提供统一输入。

## 1. 最终品牌确认

### 1.1 母品牌

英文母品牌：**Larkix**

中文辅助名：**莱启**

使用原则：

- 对外主视觉优先使用 `Larkix`。
- 中文环境可使用 `莱启` 作为辅助识别，但不强制进入主 LOGO。
- 品牌应作为个人长期品牌与产品矩阵母品牌，不只是当前网站名。

### 1.2 品牌结构

`Larkix` 是母品牌，后续产品使用统一前缀：

| 产品名 | 定位 | 视觉关系 |
|---|---|---|
| Larkix Maker | 主站、内容母站、项目展示 | 母品牌标准色 |
| Larkix Elec | 电子信息、电力电子、仿真与工程工具 | 蓝色 + 琥珀辅助色 |
| Larkix MD2FILE | Markdown 转文件工具 | 蓝色 + 紫色辅助色 |
| Larkix Sim | 仿真软件、模型与可视化方向 | 蓝色 + 青色辅助色 |
| Larkix Lab | 实验性工具、开源项目、原型集合 | 蓝色 + 绿色辅助色 |

## 2. 品牌核心

### 2.1 品牌定位

Larkix 是一个面向创作者、工程师与学习者的个人品牌，长期承载：

- 电子信息与电力电子内容。
- 仿真软件与互联网软件工具。
- 开源项目、教程、项目笔记与实践资料。
- 从个人创作起步，逐步扩展为工具与内容产品矩阵。

### 2.2 品牌气质

关键词：

- 清晨
- 蓝色晨鸟
- 启发
- 开放
- 实践
- 可靠
- 创造
- 可持续成长

希望传达的感觉：

> 清晨开始，打开知识，把想法变成可以实践的作品。

### 2.3 品牌句

中文主句：

> 从第一声清晨开始，打开创造。

英文主句：

> Open ideas from first light.

备选短句：

- Build from first light.
- Ideas take flight.
- Learn, build, and open.

## 3. 鸟形象确认

### 3.1 可以使用的鸟意象

品牌可以保留鸟作为核心形象，但建议使用抽象表达：

- 蓝色晨鸟
- 清晨第一声鸟鸣
- 展开的羽翼
- 飞行轨迹
- 晨光中的剪影

鸟的形象应服务于“清晨、启发、出发、创造”，不要成为具体物种科普。

### 3.2 不建议使用的表达

为降低与既有 `Lark / Lark Suite / 飞书` 相关品牌的混淆风险，不建议：

- 中文主品牌使用“云雀”“飞雀”“晓雀”等直译鸟名。
- 英文拆写为 `Lark IX`、`Lark-X`、`Lark iX`。
- 在品牌介绍中强调 “Lark = 云雀”。
- 将 LOGO 做成办公协作、聊天、文档套件风格。
- 使用聊天气泡、多人协作、文档协同、会议图标作为主视觉。

推荐统一表述：

> Larkix 是完整造词品牌，视觉形象为蓝色晨鸟与 X 形展开。

## 4. LOGO 设计方向

### 4.1 核心图形

建议 Agent7 围绕以下方向出 LOGO：

**蓝色晨鸟 + X 形展开 + 第一束光**

图形应同时包含三层信息：

1. **鸟翼**：代表清晨鸟鸣、轻盈、启发与出发。
2. **X**：代表探索、扩展、未知、产品矩阵。
3. **晨光入口**：代表打开知识、打开创造、从清晨开始。

### 4.2 字标

推荐字标：

```text
Larkix
```

要求：

- 不使用全大写 `LARKIX` 作为默认字标，避免过硬。
- 不使用全小写 `larkix` 作为默认字标，避免过轻。
- `x` 可以做轻微视觉强调，但不要破坏可读性。
- 字体应现代、清爽、稳定，适合技术内容与工具产品。

### 4.3 图标形态建议

可探索 3 个方向：

1. **翼形 X**
   将两片羽翼交叉成 X，保留鸟的动态感。

2. **晨鸟 L**
   用抽象鸟身形成 L，右侧由羽翼或光线形成 X。

3. **光羽图标**
   一片蓝色羽翼被晨光切开，负形中隐含 X。

### 4.4 必须适配的场景

LOGO 需同时适配：

- 导航栏横向 LOGO。
- Favicon / App icon。
- 深色模式。
- 浅色模式。
- 小程序工具页。
- GitHub / B 站 / 知乎 / 公众号头像。
- 文章封面角标。
- 子产品标识，如 `Larkix Elec`、`Larkix MD2FILE`。

## 5. 色彩系统

### 5.1 主色

Larkix 希望使用蓝色系，主色应清爽、可信、开放，不要过暗或过企业办公感。

推荐色板：

```css
:root {
  --larkix-blue: #2563EB;
  --larkix-blue-deep: #1E3A8A;
  --larkix-blue-soft: #DBEAFE;
  --larkix-sky: #38BDF8;
  --larkix-mist: #E0F2FE;
  --larkix-ink: #0F172A;
  --larkix-muted: #64748B;
  --larkix-surface: #FFFFFF;
  --larkix-bg: #F8FAFC;
}

[data-theme="dark"] {
  --larkix-bg: #07111F;
  --larkix-surface: #0F1B2D;
  --larkix-blue: #60A5FA;
  --larkix-sky: #38BDF8;
  --larkix-ink: #F8FAFC;
  --larkix-muted: #A8B6C8;
}
```

### 5.2 子产品辅助色

母品牌统一蓝色，子产品只允许增加一个辅助色：

| 子品牌 | 辅助色 | 用途 |
|---|---:|---|
| Larkix Maker | `#38BDF8` 青色 | 主站、内容、项目展示 |
| Larkix Elec | `#F59E0B` 琥珀色 | 电子、电力电子、测量、仿真 |
| Larkix MD2FILE | `#8B5CF6` 紫色 | 文档转换、文件工具 |
| Larkix Sim | `#06B6D4` 青蓝色 | 仿真、可视化 |
| Larkix Lab | `#22C55E` 绿色 | 实验工具、原型、开源项目 |

要求：

- 辅助色只用于标签、状态、局部图标，不改变母品牌蓝色主导。
- 不使用大面积渐变、发光球、装饰光斑。
- 页面整体应保持清爽、可读、工程可信。

## 6. 视觉风格

### 6.1 白天主题

页面气质：

- 清爽
- 明亮
- 开放
- 内容友好
- 适合教程、项目、工具入口

建议：

- 大面积使用浅灰白背景。
- 用蓝色作为导航、按钮、链接和品牌识别。
- 文章页保持高可读性，不做过度装饰。
- 项目卡片和工具卡片可使用轻边框与细阴影。

### 6.2 深色主题

页面气质：

- 安静
- 专业
- 工具台
- 夜间学习与开发者场景

建议：

- 深色背景不要纯黑，使用蓝黑。
- 代码块、仿真工具、参数面板优先适配深色。
- 高亮使用天蓝或青蓝，避免强紫色主导。

## 7. 与飞书 / Lark 相关的避让建议

本节仅作为品牌设计避让建议，不构成法律意见。

为了降低未来混淆风险，Agent7 在视觉设计中应注意：

- 不出现 `Lark` 单独字样。
- 不出现 `Lark Suite`、`Lark Office`、`Lark Chat`、`Lark Meeting` 等命名。
- 不使用与办公协作软件高度相似的图标语言。
- 不使用“云雀”作为中文商标或主视觉文案。
- 不把鸟画成现成的云雀插画，应做抽象晨鸟。
- 视觉中心应是 `Larkix`、`X`、晨光、启发，而不是 `Lark`。

推荐表达：

```text
Larkix is an independent personal brand and project.
```
