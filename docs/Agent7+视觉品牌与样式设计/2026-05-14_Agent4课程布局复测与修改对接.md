## P0 必改问题

### 1. 分类页脚本上线风险

问题：

在旧进程 `4173` 上，分类页只有空壳，原因是 `category-page.js` 被 403 阻断。

用户影响：

- 模拟电子、STM32、ESP32、全部教程页不会渲染课程大纲内容。
- 中间课程、右侧项目、搜索逻辑都失效。

修改要求：

- 保留当前 `server.js` 中 `/category-page.js` 白名单。
- Agent0 发布/合并后重启服务。
- Agent4 复测时必须使用新进程，不要只刷新旧进程页面。
- QA 必须检查 DevTools console 中没有：
  - `Refused to execute script`
  - `MIME type ('text/plain') is not executable`
  - `/category-page.js 403`

验收：

- `category.html?category=analog`
- `category.html?category=stm32`
- `category.html?category=esp32`
- `category.html?category=all`

以上 4 个页面都能显示真实课程内容，而不是空白三栏。

### 2. 分类页不应该显示“正文正在接入中”式误导文案

当前现象：

`analog/stm32/esp32` 每个分类只有 1 篇文章时，顶部精选学习起点已经显示文章，但下方仍显示类似：

> 本分类正文正在接入中

这会让用户误以为当前分类没有正文。

修改要求：

- 当当前分类已有文章，只是 `lesson-row` 列表为空时，不要说“正文正在接入中”。
- 文案改为“更多课程正在整理中”或“当前先展示推荐学习起点，后续课程会继续补齐”。
- 如果分类完全没有文章，再显示“正文正在接入中”。

建议逻辑：

```js
if (items.length > 0 && visibleRows.length === 0) {
  // 已有推荐学习起点，只是没有更多列表
  showMoreComingState();
} else if (items.length === 0) {
  showEmptyCategoryState();
}
```

验收：

- STM32 页已有 `STM32 ADC 模拟采样从原理到精度优化` 时，不应出现“本分类正文正在接入中”这种误导句。

### 3. 分类页搜索需要覆盖课程阶段和推荐内容

当前现象：

在模拟电子页搜索 `ADC`，页面显示没有找到正文，但左侧课程阶段里本身有 `ADC 前端`，推荐内容里也有 `STM32 ADC...`。

用户影响：

- 用户会认为搜索坏了。
- 课程阶段和推荐内容没有参与搜索，体验割裂。

修改要求：

分类页搜索至少覆盖：

- 当前分类文章标题、摘要、标签、正文。
- `courseMeta.stages`
- `courseMeta.resources`
- `courseMeta.keywords`
- `courseMeta.recommendedPosts`
- `courseMeta.relatedProjects`

最小可接受方案：

- 如果关键词命中阶段、关键词、推荐阅读或相关项目，即使正文列表为空，也不要显示“没有找到”。
- 应显示：
  - 命中的阶段 chip 高亮。
  - 推荐学习起点仍保留。
  - 右侧相关项目根据关键词过滤。
  - 空状态文案改为“正文暂无匹配，已为你保留匹配的阶段/项目入口”。

验收用例：

- `category.html?category=analog` 搜索 `ADC`。
- 左侧 `ADC 前端` 应有命中状态。
- 页面不应只显示“没有找到与 ADC 匹配的正文”。

## P1 视觉与布局修改

### 4. 首页课程路径卡片可读性不足

当前现象：

首页课程路径卡片使用大图背景，但左侧标题和摘要叠在较暗图像上，部分内容对比度偏低。

另外，右侧推荐内容区域出现较突兀的大块白色/浅色留白，和左侧暗图像割裂明显。

修改要求：

- 保留“课程路径中心”的布局。
- 保留三条路线：模拟电子、STM32、ESP32。
- 不要退回普通卡片网格。
- 但每条路线卡片需要更像一条完整路径，而不是左暗图 + 右白块拼接。

建议方案：

- 卡片整体使用白色面板。
- 左侧图片作为固定比例 media，宽度约 32%-38%。
- 中间为路线标题、摘要和阶段节点。
- 右侧为推荐内容和 CTA。
- 如果继续用背景图叠加，必须加稳定遮罩，确保标题和摘要对比度足够。
- 不要让右侧出现大面积空白渐变。

建议桌面结构：

```text
| 图片/方向视觉  | 路线标题 + 摘要 + 阶段节点 | 推荐内容 + CTA |
```

移动端：

```text
图片
路线标题
摘要
阶段节点
推荐内容
CTA
```

验收：

- 在白天主题下，课程路径卡片不应整体像夜间卡片。
- 标题、摘要、阶段节点都必须清晰可读。
- 右侧推荐区不能出现空白过大的视觉断层。

### 5. 分类页顶部区域过高，不符合“分类页不要大 Hero 化”

当前现象：

分类页顶部有较大的背景图和留白，搜索框在右侧独占区域，导致首屏有效课程内容下移。

这和 Agent7 之前要求的“分类页保持信息密度，不要大 Hero 化”有偏差。

修改要求：

- 分类页顶部保持课程介绍，但压缩高度。
- 课程标题、说明、返回首页、搜索框应更紧凑。
- 首屏应能同时看到：
  - 分类标题与说明。
  - 搜索框。
  - 三栏主体的第一行内容。

建议：

- `section-heading` 顶部上下 padding 减少。
- 搜索框可并入标题区右侧，不再单独占一整块高度。
- 背景图透明度降低或只作为轻量横幅，不要形成大 Hero。

验收：

- 1366x900 下，分类页首屏应明显看到课程大纲、精选学习起点、右侧项目卡，而不是主要被头图占据。

### 6. 夜间模式切换动效需要更克制

当前现象：

夜间模式最终状态正常，但切换过程中会出现很大的圆形过渡遮罩。截图在 300ms 左右会捕捉到一个巨大圆形，视觉上比较突兀。

修改要求：

- 保留夜间模式。
- 可以保留过渡，但需要更短、更轻。
- 建议动效时长控制在 300-450ms。
- 或者在 `prefers-reduced-motion` 下关闭。
- 如果实现复杂，第一阶段可以直接取消圆形扩散动画，使用颜色淡入淡出即可。

验收：

- 快速点击夜间模式时，页面不应出现覆盖大半屏的灰色圆形残影。
