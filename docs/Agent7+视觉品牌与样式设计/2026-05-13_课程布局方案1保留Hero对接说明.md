换句话说：这是课程信息架构与视觉布局重排，不是功能删减。

## 总体设计方向

采用“学习路径中心”布局。

核心思想：

- 首页不再只像文章流，而是成为课程入口中心。
- 模拟电子、STM32、ESP32 三个方向都要呈现为可学习的课程路径。
- 分类页从单一网格列表升级为“左侧课程大纲 + 中间课程内容 + 右侧资源工具”的学习页面。
- 仍然使用当前 Agent7 品牌体系：15 号 LOGO、白天 05 主题、夜晚 02 主题。

视觉原则：

- 白天：`#F4F7FB` 页面底、`#FFFFFF` 面板、`#0F4EA8/#0D6FD3` 蓝色主视觉、少量 `#F2A316` 强调。
- 夜晚：沿用现有夜间模式，不新增独立夜间机制。
- 纯色为主，不使用新的大面积渐变。
- 卡片圆角不超过 8px。
- 避免嵌套卡片。
- 页面更像课程系统，而不是营销首页。

## 首页布局说明

### 1. Header

保持现状。

包括：

- LOGO。
- 主导航：模拟电子、STM32、ESP32、开源项目、小程序。
- 搜索框。
- 夜间模式切换。
- 管理端入口。

不建议改动 header 的功能结构。

### 2. Hero

必须保留当前 Hero。

保持现有：

- `section.site-shell.hero`
- `hero-bg`
- `heroCopy`
- `heroCards`
- `pagination-dots`
- `main.js` 中 Hero 数据绑定与切换逻辑

只允许在必要时做轻微视觉适配，例如外边距、下方衔接 spacing，但不改变 Hero 的内容模型和交互。

### 3. Hero 下方新增/重排：课程路径中心

在 Hero 后新增一个核心课程区，替代当前“最新教程”作为首页第一学习入口。

建议 section 名称：

`course-path-section`

结构：

- 左侧或上方：区块标题
  - 中文：`课程路径`
  - 英文/副标题：`Learning Paths`
  - 简短说明：说明可按模拟电子、STM32、ESP32 三条路线系统学习。
- 主体：三条横向课程路径卡/路径行
  - 模拟电子
  - STM32
  - ESP32

每条课程路径建议包含：

- 方向名称。
- 简短一句说明。
- 3-5 个阶段节点，例如：
  - 模拟电子：基础器件 → 运放与滤波 → ADC 前端 → 电源与噪声 → 实验验证
  - STM32：开发环境 → GPIO/定时器 → ADC/DMA → 通信接口 → 综合项目
  - ESP32：联网基础 → 传感器节点 → MQTT/OTA → 低功耗 → 长期部署
- 最近/推荐文章 2-3 篇。
- CTA：
  - `进入路线`
  - 链接到对应 `category.html?category=...`

布局建议：

- 桌面端：三条横向路径上下排列，每条像一条课程路线，而不是普通文章卡。
- 每条路径内部可以使用步骤节点、连线、阶段标签。
- 右侧可以放该方向最新文章的小预览。
- 移动端：三条路径纵向堆叠，阶段节点横向滚动或自动换行。

### 4. 小程序区

保留当前小程序区，但位置可以调整到课程路径之后。

建议：

Hero → 课程路径 → 小程序工具 → 最新教程 → 开源项目

原因：

- 小程序是学习过程中的工具支撑，放在课程路径后更合理。

不删除：

- `home-miniapp-section`
- `miniappUpdateList`
- 现有 `data/miniapps.js` 渲染。

### 5. 最新教程区

保留，但从“主入口网格”变成“近期更新”。

建议标题：

- 中文：`近期更新`
- 英文：`Recent Lessons`

布局：

- 不再只是均匀卡片网格。
- 可以改成：
  - 左侧一篇重点更新。
  - 右侧 4-6 篇紧凑列表。
- 或保留网格，但应增加“所属路线/阶段”信息。

数据仍来自现有 `articleList`。

### 6. 开源项目区

保留。

建议让它和课程路径产生关系：

- 标题仍可为 `开源项目`。
- 卡片增加“关联课程方向”或“项目阶段”视觉标签。
- 不改变项目数据结构时，可先只做视觉标签和排版优化。

## 分类页通用布局

适用于：

- `category.html?category=analog`
- `category.html?category=stm32`
- `category.html?category=esp32`

目标：从“标题 + 文章网格”改为课程学习页。

### 1. 顶部 Header

保持现状。

必须保留：

- LOGO。
- 主导航。
- 夜间模式按钮。
- 管理端入口。

### 2. 分类页顶部课程介绍区

当前 `section-heading` 可以保留语义，但视觉上升级为课程头部。

内容：

- 分类中文标题。
- 英文标题。
- 分类说明。
- 内容数量。
- 返回首页链接。

新增可选信息：

- 推荐学习方式。
- 难度范围。
- 典型项目结果。

但不要大 Hero 化，分类页应保持信息密度。

### 3. 三栏课程布局

分类页主体改为三栏：

#### 左栏：课程大纲 / Syllabus Rail

功能：

- 展示该分类的学习阶段。
- 提供视觉锚点和筛选感。

建议宽度：

- 桌面端约 220-260px。

内容示例：

模拟电子：

- 基础器件
- 运放与反馈
- 滤波器
- ADC 前端
- 电源与噪声
- 测量与调试

STM32：

- 开发环境
- GPIO 与定时器
- ADC 与 DMA
- 通信接口
- Bootloader
- 调试与优化

ESP32：

- Wi-Fi 基础
- 传感器节点
- MQTT 通信
- OTA 升级
- 低功耗
- 部署维护

实现注意：

- 初期可以是静态阶段标签，不一定马上做真实筛选。
- 如果 Agent0/Agent4 有精力，可做点击筛选；但不应阻塞布局落地。

#### 中栏：课程内容主体

功能：

- 承载文章列表。
- 按阶段或难度分组。

建议结构：

- 顶部：精选/推荐学习起点。
- 下方：分组课程卡列表。

卡片内容保留现有文章信息：

- 封面图。
- 分类标签。
- 标题。
- 摘要。
- 阅读时间。
- 日期。
- 链接到 `post.html?id=...`

卡片布局建议：

- 桌面端用横向课程条目，而不是全部大卡片。
- 每个条目左侧图片，右侧标题摘要和元信息。
- 增加阶段标签，例如 `入门`、`实验`、`进阶`、`项目`。

不要删除任何文章。

#### 右栏：资源 / 工具 / 快捷入口

功能：

- 增加课程学习辅助感。
- 与小程序、项目、资料形成连接。

建议宽度：

- 桌面端约 260-300px。

内容可包含：

- 本方向推荐工具。
- 关联小程序。
- 关联开源项目。
- 常用关键词。
- 推荐实验路径。

示例：

模拟电子右栏：

- ADC 精度检查清单
- 运放选型笔记
- 滤波器实验
- 关联项目：模拟采样前端

STM32 右栏：

- ADC/DMA 检查清单
- 定时器采样触发
- 串口调试工具
- 关联项目：STM32 ADC 采样链路

ESP32 右栏：

- MQTT 节点调试
- OTA 检查清单
- 低功耗测量
- 关联项目：ESP32 传感器节点

### 4. 移动端布局

移动端顺序：

1. 分类标题与说明。
2. 横向滚动课程阶段。
3. 推荐学习起点。
4. 课程内容列表。
5. 资源/工具区。

注意：

- 右栏不能在移动端挤压正文。
- 大纲栏改为横向 chips 或 sticky 横向滚动条。
- 所有按钮和标签不能文字溢出。

## `all` 分类页

`category.html?category=all` 不适合显示某一个方向的大纲。

建议：

- 标题为全部教程。
- 左栏改为方向筛选：
  - 全部
  - 模拟电子
  - STM32
  - ESP32
- 中栏显示全部文章。
- 右栏显示“推荐学习路线”而不是单方向资源。
