## 3. 前端接入方式

### 3.1 低风险接入

在 `styles.css` 末尾追加：

```css
@import "./styles/larkix-brand-theme.css";
```

这样不会改动现有 `00-base.css` 的历史内容，只通过后导入覆盖变量。

### 3.2 正式合并方式

确认全站切换到 Larkix 新品牌后，可以把 `styles/larkix-brand-theme.css` 中的变量合并进 `styles/00-base.css` 的 `:root`、`[data-theme="dark"]` 和 `@media (prefers-color-scheme: dark)` 段落。

合并时注意：
- 保留现有 `--radius`、`--page`、`--transition`、`--theme-duration`、`--theme-ease` 等布局和动效变量。
- 用新文件中的 `--bg`、`--surface`、`--ink`、`--muted`、`--line`、`--blue`、`--theme-accent` 覆盖旧品牌色。
- `--brand-logo` 建议改为英文横向版 `larkix-final-white-bg-lockup.svg`。

## 6. 使用规范

### 6.1 LOGO

- 导航栏优先使用英文横向 SVG。
- 方形头像、favicon、App icon 使用纯图标 SVG。
- 浅色背景下使用原始白底图标即可。
- 深色背景中，图标外部如果没有白底容器，必须加白色或浅色容器，避免深紫后翼被背景吞掉。
- 不要重新给 LOGO 加渐变、描边、阴影或发光效果。

### 6.2 页面配色

- 页面大背景使用 `--larkix-bg`，不要使用纯紫大面积铺底。
- 卡片和文章正文使用 `--larkix-surface`。
- 二级工具区域、标签背景和轻量提示使用 `--larkix-panel` 或 `--larkix-primary-soft`。
- 主要按钮、链接、当前导航项使用 `--larkix-primary`。
- 暖色 `--larkix-accent` 只用于少量提示、精选、版本号或重要状态，不要作为大面积主色。

### 6.3 黑夜模式

- 黑夜背景不要使用纯黑，统一使用 `#0B0712`。
- 黑夜卡片使用 `#120A1F`，需要更高层级时使用 `#1B102B`。
- 黑夜正文使用 `#F8FAFC`，辅助文本使用 `#B6A8C9`。
- 黑夜模式边框保持低对比，优先 `#2A1740` 或透明紫灰。

## 7. 主题切换建议

当前项目已有 `[data-theme="dark"]` 和 `prefers-color-scheme` 结构，建议继续沿用。

```js
document.documentElement.dataset.theme = "dark";
document.documentElement.dataset.theme = "light";
delete document.documentElement.dataset.theme;
```

建议含义：
- `dark`：用户手动选择黑夜。
- `light`：用户手动选择白天。
- 无 `data-theme`：跟随系统。

## 8. 前端 QA 清单

接入后请检查：

- 首页导航 LOGO 是否替换为 `larkix-final-white-bg-lockup.svg`。
- 白天模式正文、卡片、按钮、标签是否使用 02 方案。
- 黑夜模式背景是否为柔和深紫黑，而不是旧蓝黑。
- 文章页代码块、目录、搜索框在黑夜模式下是否有足够对比度。
- 主按钮 hover/active 不要变成高饱和蓝色。
- 焦点态 outline 使用紫色，不再使用旧蓝色。
- 移动端导航和卡片边框不要发灰或过亮。
- LOGO 在深色导航或深色卡片中必须有白底容器或使用横向白底资产。

## 9. 建议下一步

1. 先在 `styles.css` 末尾 import `styles/larkix-brand-theme.css` 做全站视觉预览。

3. 没有冲突后，再把变量合并进 `styles/00-base.css`。
4. 最后删除或归档旧 Gokotta / blue brand token，避免后续维护时混用。
