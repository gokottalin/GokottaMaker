## 2. 运行与技术构成

项目运行形态：

- Node.js 原生 HTTP 服务，入口为 `server.js`。
- Node 要求：`>=22.5.0`，启动需 `--experimental-sqlite`。
- 内容数据主要来自 SQLite 和上传目录，静态 JS/Markdown 数据更多是种子、回退或源稿。
- 本地默认访问：`http://localhost:4173`。
- 管理端入口：`http://localhost:4173/admin/`。
- 生产推荐拓扑：Nginx/HTTPS -> `127.0.0.1:4173` -> Node 服务 -> SQLite + uploads。

关键命令：

```powershell
npm.cmd run check:version
npm.cmd run test:markdown
node --experimental-sqlite server.js
```

生产健康检查通常使用：

```text
/healthz
```

## 4. 当前架构主线

当前架构主线来自 Agent00 的公式变量推导网络与电力电子聚焦站点需求：

- 作者在文章公式中可以高亮某个变量。
- 点击变量进入独立推导详情页。
- 推导页支持 Markdown、图片、公式、表格、代码块、嵌套变量链接。
- 推导节点应形成可维护知识图谱，而不是孤立页面。
- CMS 需要支持安全编辑推导节点。
- 公开站点可以临时聚焦首页 + 电力电子 + 推导页，其它内容隐藏但不删除。

- 允许 dangling derivation links，CMS 警告，公开端安全降级。
- DOCX V0 退化为 `label [derive:slug]` 文本，不做超链接关系。
- 推导公开路由固定为 `derive.html?slug=<slug>`。
- `public_focus_mode` 进入 V0 site setting，默认关闭。
- canonical 字段为 `publishStatus`、`visibilityStatus`。
- 隐藏落地页不进 sitemap 并 noindex，旧详情页不批量 noindex。
- `rollback.sh` 默认服务名风险需在发布前闭环，目标服务名为 `gokottamaker`。
- knowledge-node 保存响应为 `{ node, nodes, warnings }`。
