## 总体决策

采用 Agent7 的「课程布局方案 1：学习路径中心」。

本轮目标不是重做首页，也不是替换现有 Hero，而是在保留现有 Hero、搜索、夜间模式、管理端入口、小程序入口、文章和项目渲染逻辑的前提下，把网站的信息架构升级为“课程路径 + 文章内容 + 项目实践”的结构。

## 保护边界

以下内容默认冻结，除非 Agent0 单独批准：

- 首页 Hero：`section.site-shell.hero`
- Hero 背景轮播：`.hero-bg`
- Hero 主文案：`#heroCopy`
- Hero 右侧轮播卡片：`#heroCards`
- Hero 点状分页：`.pagination-dots`
- Header、Logo、搜索框、管理端入口、小程序入口
- 夜间模式 `data-theme` 逻辑
- `home-miniapp-section`、`miniappUpdateList`、`data/miniapps.js`
- 现有文章、项目链接、封面、标签、日期、阅读时间
- 后端数据结构和 SQLite schema

## 执行顺序

### 1. Agent5：内容、SEO 与知识体系

优先级：P0
执行顺序：第一步
职责：先给 Agent4 提供稳定的课程信息内容，不直接改核心页面结构。

输入：

- Agent7 课程布局方案
- 当前文章分类：模拟电子、STM32、ESP32、开源项目
- 当前文章和项目数据

输出：

- 三条课程路径的文案和阶段定义：Analog、STM32、ESP32
- `courseMeta` 建议结构
- 每条路线 3-5 个阶段名
- 每条路线 2-3 篇推荐内容
- Category 页面右侧资源区文案：工具、关键词、相关项目

接口约定：

```js
courseMeta = {
  analog: {
    title: "模拟电子",
    english: "Analog Electronics",
    summary: "...",
    stages: ["基础指标", "运放与滤波", "测量验证", "项目实践"],
    resources: ["示波器", "信号源", "滤波器设计"],
    keywords: ["ADC", "运放", "低通滤波"]
  }
}
```

不得修改：

- `server.js`
- SQLite schema
- Hero 轮播逻辑
