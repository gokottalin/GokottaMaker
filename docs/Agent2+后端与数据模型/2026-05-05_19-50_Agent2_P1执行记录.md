## 5. 当前保留风险

1. `server.js` 仍包含上传、SEO、静态资源、健康检查和路由层，下一轮可继续拆 `lib/uploads.js`、`lib/seo.js`、`lib/static.js`。
2. `categories` 已建表，但 `posts` 仍保留 `category/category_key` 字段作为当前 API 契约；下一轮可设计兼容迁移到 `category_id`。
3. `tags` 已有正式表和关联表，但管理端仍以字符串输入，暂未提供正式标签管理 UI。
4. `published_at` 当前为首次进入 published 状态时记录；如果后续需要“取消发布后再次发布更新时间”，需要另设策略。
5. 工作区存在其他 Agent 的并行改动，提交前建议按 Agent 范围分组审查。
