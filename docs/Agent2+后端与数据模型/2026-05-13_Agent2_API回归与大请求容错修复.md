## 本轮完成项

### 1. 增强 API 回归脚本

已补强脚本：`scripts/verify-api.ps1`

新增覆盖：

- `/api/content` 响应头包含 `charset=utf-8`
- 公共内容中包含可正常解析的中文标题
- 管理端内容中轮播槽位必须正好为 `0,1,2,3`
- `/api/md2file/convert` 成功导出 DOCX
- `/api/md2file/convert` 对空 Markdown 返回 400
- `/api/md2file/convert` 对不支持格式返回 400
- `/api/md2file/convert` 对超大 Markdown 返回 413

### 2. 修复大请求直接断连接的问题

修复文件：`server.js`

修复点：

- 旧逻辑在 `readBody()` 超限时直接 `req.destroy()`
- 结果是客户端收到 `Empty reply from server` 或连接被关闭
- 这不利于前端和测试工具稳定识别 `413 Payload Too Large`

修复后：

- 请求超限时不再粗暴断开连接
- 改为在请求读完后稳定返回 `413`
- 保持 JSON 错误响应路径一致

这项修复直接覆盖今天总控要求里的“大小限制和错误返回”。
