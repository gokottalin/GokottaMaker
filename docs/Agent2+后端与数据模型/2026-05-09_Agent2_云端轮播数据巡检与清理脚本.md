## 3. 已新增脚本

### 只读巡检

跨平台 Node 脚本：

```text
scripts/check-carousel-db.js
```

Linux 服务器包装脚本：

```text
scripts/check-carousel-cloud.sh
```

服务器执行：

```bash
cd /opt/LarkixMaker
bash scripts/check-carousel-cloud.sh
```

或显式指定数据库：

```bash
node --experimental-sqlite scripts/check-carousel-db.js --db /srv/gokottamaker-data/database/gokottamaker.sqlite
```

输出字段：

```text
ok
featuredCount
duplicateSlots
outOfRange
items
```

如果 `featuredCount > 4`、存在重复槽位、存在 `featuredOrder` 不在 `0-3`，脚本退出码为 `2`。

### 清理脚本

跨平台 Node 脚本：

```text
scripts/cleanup-carousel-db.js
```

Linux 服务器包装脚本：

```text
scripts/cleanup-carousel-cloud.sh
```

默认 dry-run，不改数据库：

```bash
cd /opt/LarkixMaker
bash scripts/cleanup-carousel-cloud.sh --dry-run
```

确认输出无误后执行清理：

```bash
cd /opt/LarkixMaker
sudo bash scripts/cleanup-carousel-cloud.sh --apply
```

`--apply` 会先备份 SQLite 主库、WAL、SHM 到：

```text
/srv/gokottamaker-backups/carousel-cleanup-YYYY-MM-DD_HH-MM-SS/
```

清理策略：

1. 只处理 `featured = 1` 且 `deleted_at IS NULL` 的文章/项目。
2. 只保留 `featuredOrder` 在 `0-3` 的项目。
3. 同一槽位重复时，优先保留已发布内容，再按更新时间较新的保留。
4. 超出 4 条、重复槽位、越界槽位的其余项会被设置为：

```sql
featured = 0,
featured_order = 0,
updated_at = CURRENT_TIMESTAMP
```

真实本地数据库未被清理脚本修改。

## 5. 建议服务器操作

先确认服务状态，因为公网当前返回 502：

```bash
sudo systemctl status gokottamaker --no-pager
sudo journalctl -u gokottamaker -n 120 --no-pager
curl -fsS http://127.0.0.1:4173/healthz
```

然后执行只读巡检：

```bash
cd /opt/LarkixMaker
bash scripts/check-carousel-cloud.sh
```

如果输出 `ok: true`，无需清理。

如果输出 `featuredCount > 4`、`duplicateSlots` 非空或 `outOfRange` 非空：

```bash
cd /opt/LarkixMaker
bash scripts/cleanup-carousel-cloud.sh --dry-run
sudo bash scripts/cleanup-carousel-cloud.sh --apply
bash scripts/check-carousel-cloud.sh
sudo systemctl restart gokottamaker
curl -fsS http://127.0.0.1:4173/api/content
```

## 6. 风险说明

- 本脚本不会删除文章、项目或上传图片，只会取消多余轮播标记。
- `--apply` 前会备份 SQLite 文件。
- 清理脚本不会自动重新分配空缺槽位；它只禁用越界、重复或超量项，避免误改运营排序。
