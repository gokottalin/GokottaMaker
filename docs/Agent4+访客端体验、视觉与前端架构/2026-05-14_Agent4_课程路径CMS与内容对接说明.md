- 首页 `课程路径` 卡片：
  - 左侧图片已改为融入模块的背景层，不再把正文挤到右边。

## 3. Agent5 内容接入要求

### 课程正文

分类页搜索和正文列表依赖 `posts` 数据，最少需要这些字段：

- `id`
- `title`
- `category`
- `excerpt`
- `date`
- `readTime`
- `cover`
- `markdown`
- `tags`

### 项目映射

分类页右侧项目栏依赖 `relatedProjects` 中的项目 ID，项目数据最少需要：

- `id`
- `title`
- `summary`
- `status`
- `statusKey`
- `cover`
- `license`
- `stars`

## 4. 当前路由与内容对应关系

- `analog`
  - 正文：模拟电子相关文章
  - 项目：优先接 `power-amp`、`programmable-power`
- `stm32`
  - 正文：STM32 相关文章
  - 项目：优先接 `logic-analyzer`、`programmable-power`
- `esp32`
  - 正文：ESP32 相关文章
  - 项目：优先接 `smart-home-hub`

## 5. 空状态文案策略

当某分类暂无正文时，前端会显示：

- 路线骨架仍保留
- 推荐学习起点仍可进入
- 右侧相关项目仍可进入

所以内容 Agent 只要逐步补正文，不需要等整条路线一次性齐备再上线。

## 6. 后续建议

下一步如果 Agent3 / Agent2 要把这套从本地覆盖升级到数据库，可直接沿用：

- 存储键名：`course_meta`
- 数据结构：与 `window.GokottaCourseMeta` 保持一致
- 写入策略：整条路线对象覆盖
- 前台读取策略：数据库值优先，缺字段时回退默认配置
