# 2026-05-14 Agent4 P0 修复：BUG-010 移动端课程路径横向溢出

日期：2026-05-14
来源：`docs/Agent0+总控与集成/2026-05-14_23-20_第4次复测结果处理与分工.md`

## 问题

390px 移动端首页课程路径区出现横向溢出，不满足“移动端无横向滚动”的发布门槛。

## 修改

文件：

- [styles/40-responsive.css](/D:/Project/26-WEB/GokottaMaker/styles/40-responsive.css)

处理：

- 在 `max-width: 760px` 断点中显式将 `.course-path-card` 改为单列 `grid-template-columns: 1fr`
- 同时收紧以下内部容器，避免子元素继续把卡片撑宽：
  - `.course-path-copy`
  - `.course-path-side`
  - `.course-steps`
  - `.course-path-title-line`
- 给 `.course-path-card` 增加 `overflow: hidden`
- 给 `.course-step` 增加 `max-width: 100%`

## 验证

### 390 x 844 移动端

检查结果：

```json
{
  "scrollWidth": 390,
  "clientWidth": 390,
  "cardCount": 3,
  "firstCardWidth": 372,
  "shellWidth": 372
}
```

结论：

- 满足 `document.documentElement.scrollWidth <= document.documentElement.clientWidth + 2`
- 首页课程路径区已无横向滚动

### 1366 x 900 桌面端回归

检查结果：

```json
{
  "scrollWidth": 1366,
  "clientWidth": 1366,
  "gridColumns": "449.391px 459.656px 330.953px",
  "cardWidth": 1326
}
```

结论：

- 桌面端仍然保持三段式课程路径卡
- 本次修复仅影响小屏断点，不影响桌面布局
