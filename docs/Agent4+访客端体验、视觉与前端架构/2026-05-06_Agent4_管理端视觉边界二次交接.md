# Agent4 管理端视觉边界二次交接

时间：2026-05-06 09:13  
版本：V2.1.0+20260506-0913

## 与 Agent4 相关的变化

- 管理端编辑页现在是“主页面预览 + 右侧编辑浮窗”。
- 预览区域是主页面主体，不允许被内容列表或系统状态打断。
- 编辑浮窗在桌面端固定在右侧，宽约 500px，需要保持清晰、轻量、高可读。
- 内容列表与系统状态改为独立管理视图。

## 视觉边界

- 可以优化编辑浮窗的材质、边框、阴影和透明层次。
- 不要把编辑浮窗做得过窄，编辑体验优先级高于装饰效果。
- 预览区样式应尽量贴近访客端 Markdown 阅读效果。
- 访客端公共 `.markdown-article` 样式如有调整，需要检查管理端 Preview 是否被污染。

## 后续建议

- 可为右侧编辑浮窗增加工程仪表面板式细节，但保持克制。
- 可为导航视图增加更明确的 active 状态。
- 若生成管理端视觉资产，需与现有蓝色科技风保持一致。
