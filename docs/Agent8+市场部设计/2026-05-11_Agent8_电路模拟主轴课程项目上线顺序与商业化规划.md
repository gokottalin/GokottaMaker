# Agent8 电路模拟主轴课程、项目上线顺序与商业化规划

生成时间：2026-05-11
项目：LarkixMaker
战略主轴：电路模拟/电路分析为主，STM32 作为实测验证平台
目标人群：中国硬件工程师、嵌入式工程师、电子专业学生、项目型 Maker
执行约束：单人运营，每天 2-3 小时

## 1. 最终定位

LarkixMaker 后续不应做成“STM32 教程站”，而应做成：

> 用电路模拟解释硬件问题，用 STM32 实测验证工程结果的电子技术品牌。

推荐内容比例：

| 方向 | 占比 | 作用 |
|---|---:|---|
| 电路模拟/电路分析 | 60% | 技术壁垒和付费核心 |
| STM32 实测验证 | 30% | 流量入口和工程落地 |
| 项目复现/资料包 | 10% | 收入产品和品牌资产 |

核心主线：

```text
信号源/传感器 -> RC/保护 -> 运放/缓冲 -> ADC 输入 -> STM32 ADC/DMA -> 数据处理 -> 误差评估
```

## 2. 信息收集结论

### 2.1 免费供给很强

外部资料显示：

- Analog Devices 官方 LTspice 是免费 SPICE 仿真软件，适合模拟电路仿真。
- ST 官方 STM32 MOOC 和在线课程免费，STM32 基础教学供给很强。
- TI Precision Labs 提供面向模拟信号链、运放、ADC/DAC 等方向的视频和参考资料。
- 嘉立创 EDA 专业版官方提供原理图、PCB、器件创建、仿真等视频教程入口。

判断：

- “LTspice 怎么下载安装到能画第一个电路”不适合收费。
- “STM32 如何点灯、配置 HAL、创建工程”不适合收费。
- “嘉立创 EDA 基础操作”不适合收费。
- 能收费的是：仿真模型、工程参数、实测数据、问题闭环、可复现项目。

### 2.2 价格锚点

可见市场样本：

| 市场样本 | 价格信号 | 对 LarkixMaker 的启发 |
|---|---:|---|
| 电子发烧友 STM32 小专题课程 | 29 元 | 低价资料包可从 29-39 元起步 |
| 电子发烧友 VIP | 月卡 89 元、年卡 279 元、优惠年卡 199 元 | 会员要有大量内容后再做 |
| 移知教育高阶课程 | 1999-5499 元及以上 | 高阶工程内容能收费，但需要强背书 |
| 凡亿教育硬件/PCB/EMC 特训 | 3499-6999 元常见 | 高价训练营依赖服务、作业、点评和项目实战 |

LarkixMaker 当前从零开始，合理价格应避开高价培训，先用低价工程资产建立信任。

## 3. 商业模式确认

最适合当前项目的商业闭环：

```text
免费文章/视频 -> 专题页 -> 低价资料包 -> 项目复现包 -> 小班课/审阅服务
```

不建议优先做：

- 纯广告。
- 泛 STM32 入门课。
- 泛 LTspice 入门课。
- 一开始做会员站。
- 一开始卖开发板库存。

建议优先做：

- 电路模拟案例。
- STM32 实测验证。
- 仿真 + 实测资料包。
- 可复现 ADC/模拟前端项目。
- 后期原理图审阅服务。

## 8. 技术壁垒规划

### 8.1 壁垒一：仿真到实测的误差矩阵

每个案例都沉淀：

| 数据 | 说明 |
|---|---|
| 理论计算 | 公式、边界、参数 |
| LTspice 仿真 | 电路文件、波形、参数扫描 |
| STM32 实测 | ADC 数据、DMA 缓冲、采样频率 |
| 仪器截图 | 示波器、万用表、逻辑分析仪 |
| 差异解释 | 为什么仿真和实测不一致 |

这是最强壁垒，因为它不是单纯复制资料能完成的。

### 8.2 壁垒二：Larkix 标准实验模板

每个课程/项目都使用同一套模板：

```text
问题现象 -> 电路模型 -> 仿真设置 -> 参数扫描 -> STM32 实测 -> 数据处理 -> 修正建议 -> 检查清单
```

长期以后，用户会记住这是 LarkixMaker 的技术风格。

### 8.3 壁垒三：调试波形库

持续积累：

- 采样时间太短导致读数偏低。
- 源阻抗过高导致通道串扰。
- 运放输出摆幅不足导致削顶。
- GBW 不足导致滤波器响应偏差。
- Vref 纹波导致 ADC 周期性抖动。
- 地线回流导致采样噪声升高。

波形库可以部分免费，完整版本作为付费资料包或项目包权益。

### 8.4 壁垒四：工具化能力

优先做 4 个小工具：

| 工具 | 目的 | 商业作用 |
|---|---|---|
| ADC 采样时间计算器 | 估算源阻抗和采样周期 | 导向 ADC 资料包 |
| 分压采样误差计算器 | 估算功耗和采样误差 | 导向 ADC 前端包 |
| RC 滤波器计算器 | 估算截止频率和阻容组合 | 导向 LTspice 包 |
| 运放选型检查器 | 检查 GBW、压摆率、输出摆幅 | 导向运放调试包 |

工具免费开放，但高级案例和完整模板付费。

### 8.5 壁垒五：可复现项目版本化

每个项目包必须有：

- 版本号。
- 更新日志。
- BOM 版本。
- 替代料说明。
- 测试条件。
- 已知问题。
- 复现 FAQ。

这会让品牌从“写文章的人”升级为“能交付工程资产的人”。

## 9. 是否完全免费

### 9.1 完全免费的好处

- 初期传播快。
- 降低关注门槛。
- 对中国工程师更友好。
- 更容易积累评论、私信和问题。
- SEO 和外部平台转发阻力小。

### 9.2 完全免费的风险

- 难以验证用户是否愿意付费。
- 实测和项目复现成本无法回收。
- 用户容易把品牌当成普通资料站。
- 资料容易被搬运，品牌识别度下降。
- 后续突然收费会产生心理落差。

### 9.3 推荐策略

不完全免费，采用：

> 75% 免费内容 + 25% 付费工程资产。

免费给：

- 原理解释。
- 关键思路。
- 部分代码片段。
- 部分仿真截图。
- 部分测试数据。
- 基础工具。

付费给：

- 完整 LTspice 文件。
- 完整 CubeMX/STM32 工程。
- 完整 Excel/计算表。
- 完整测试记录。
- 完整波形库。
- 完整项目文件。
- 问题审阅和答疑。
