## 本轮发布范围

- 首页轮播固定 4 个槽位，排序只允许 `0, 1, 2, 3`。
- CMS 增加槽位视图，可填入当前内容、替换已有槽位、取消槽位内容。
- 服务器端继续校验轮播数量上限和排序范围。
- 新增云端数据库巡检与清理脚本。
- 保留上传图片静态访问修复，重点验证 `/uploads/*` 是否能从云端读取。

## 发布后必须验收

1. 云端健康检查返回 `ok: true`，版本为 `V2.2.6+20260509-0833`。
2. 首页轮播最多显示 4 个内容。
3. 管理端只能选择轮播排序 `0-3`。
4. 同一个槽位不能被多个内容占用；如历史数据已污染，先执行清理脚本。
5. 上传图片后，访客端和管理端都能通过公网稳定读取。
