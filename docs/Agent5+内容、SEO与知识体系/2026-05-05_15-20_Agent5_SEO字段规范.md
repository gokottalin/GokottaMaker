# Agent5 SEO 字段规范

生成时间：2026-05-05 15:20
适用范围：首页、分类页、文章详情页、项目详情页、RSS、Sitemap、CMS 字段校验。

## 1. 字段规范

| 字段 | 规范 | 示例 |
|---|---|---|
| 页面标题 | 20-32 个中文字符优先，包含核心对象和收益点 | `STM32 ADC 采样精度优化：采样时间、DMA 与滤波` |
| Meta 描述 | 70-110 个中文字符，说明场景、方法和读者收益 | `围绕 STM32 ADC 的采样时间、DMA 环形缓冲、参考电压和软件滤波，整理一套稳定可信的模拟采样链路。` |
| Slug | 小写英文、数字和连字符，长期稳定 | `stm32-adc-dma-precision` |
| 摘要 | 40-80 个中文字符，适合首页卡片和 RSS | `围绕采样时间、DMA 环形缓冲、参考电压和软件滤波，建立稳定可信的 ADC 采样链路。` |
| 封面 alt | 描述画面和主题，不写“图片” | `STM32 开发板连接示波器进行 ADC 采样调试` |
| 标签 | 4-8 个文章标签，5-10 个项目标签 | `STM32,ADC,DMA,采样时间,环形缓冲,校准,调试,设计指南` |

## 4. 详情页 SEO

文章详情页和项目详情页不应只更新 `document.title`，后续应同步更新：

- `<meta name="description">`
- `<link rel="canonical">`
- `og:title`
- `og:description`
- `og:type`
- `og:image`
- JSON-LD

短期字段来源：

| SEO 字段 | 文章来源 | 项目来源 |
|---|---|---|
| title | `item.title` | `item.title` |
| description | `item.excerpt` | `item.summary` |
| canonical | `SITE_URL/post.html?id=${id}` | `SITE_URL/project.html?id=${id}` |
| og:image | `item.cover` | `item.cover` |
| published date | `item.date` | `item.date` |
| tags | `item.tags` | `item.tags` |

## 5. JSON-LD 建议

文章优先使用 `TechArticle`，无法满足时使用 `BlogPosting`。

```json
{
  "@context": "https://schema.org",
  "@type": "TechArticle",
  "headline": "文章标题",
  "description": "文章摘要",
  "datePublished": "2026-05-03",
  "author": {
    "@type": "Person",
    "name": "LarkixMaker"
  },
  "publisher": {
    "@type": "Organization",
    "name": "LarkixMaker"
  }
}
```

项目页可使用 `CreativeWork`：

```json
{
  "@context": "https://schema.org",
  "@type": "CreativeWork",
  "name": "项目名称",
  "description": "项目摘要",
  "license": "MIT License",
  "datePublished": "2026-05-03"
}
```

## 6. RSS 规范

RSS 当前基础可用，后续建议补齐：

| 字段 | 建议 |
|---|---|
| channel language | `zh-CN` |
| lastBuildDate | 使用当前生成时间或最新文章日期 |
| item category | 使用文章 `category` |
| item description | 使用 `excerpt`，不直接塞全文 |
| item guid | 保持稳定 URL |

## 7. Sitemap 规范

短期保持现有 URL，后续优化：

| 页面 | priority | changefreq | lastmod |
|---|---:|---|---|
| 首页 | 1.0 | daily | 最新内容日期 |
| 分类页 | 0.8 | weekly | 分类下最新内容日期 |
| 文章详情 | 0.7 | monthly | `date` 或未来 `updated_at` |
| 项目详情 | 0.7 | monthly | `date` 或未来 `updated_at` |

长期建议将 `post.html?id=...` 和 `project.html?id=...` 升级为语义路径，例如：

```text
/posts/stm32-adc-dma-precision
/projects/logic-analyzer
```

该变更涉及路由、canonical 和历史 URL 兼容，应由 Agent2/Agent4 协作完成，不建议只由 Agent5 单独修改。

## 9. 发布前 SEO 检查

发布前至少检查：

1. title 是否唯一，且包含核心对象。
2. description 是否能独立说明页面价值。
3. slug 是否稳定，不包含日期和无意义编号。
4. tags 是否来自受控词表。
5. cover 是否有明确 alt。
6. 文章是否至少有 2 个可内链对象：前置知识、相关项目或后续文章。
7. RSS 中是否能看到正确标题和摘要。
8. Sitemap 中是否包含该页面 URL。
