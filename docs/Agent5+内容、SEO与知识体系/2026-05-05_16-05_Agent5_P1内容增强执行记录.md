## 4. 需要用户明确授权的事项

如果要让当前本地 SQLite 中已有项目正文也立即替换为新版项目模板，需要执行一次内容覆盖或迁移。该操作会覆盖已有项目 Markdown，可能影响管理员已编辑内容，因此未自动执行。

建议只有在确认当前 SQLite 项目正文仍是初始种子、没有人工编辑价值后，再执行覆盖。
