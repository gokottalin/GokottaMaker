# Agent5 首页轮播内容策略

时间：2026-05-08 23:13
目标版本：V2.2.6+20260508-2254

## 目标

为首页 4 个轮播槽位建立内容选择规则，让轮播不是随机堆内容，而是展示 LarkixMaker 的技术主线。

## 输入

- 当前四个方向：模拟电子、STM32、ESP32、独立开源项目
- `data/posts.js`
- `data/projects.js`
- RSS/Sitemap 输出

## 输出

- 4 个轮播槽位的运营标准。
- 标题、摘要、封面规范。
- 内容是否适合上首页轮播的检查清单。

## 建议

| 槽位 | 内容策略 |
|---:|---|
| 0 | 当前最重要的核心教程或代表性项目 |
| 1 | STM32/ESP32 中最有工程价值的文章 |
| 2 | 模拟电子基础能力文章 |
| 3 | 开源项目或长期项目进度 |
