# Agent5 分类与标签词表

生成时间：2026-05-05 15:10
适用范围：`content/posts/`、`data/posts.js`、`data/seed.js`、管理端 tags 字段、未来 tags/categories 数据模型。

## 1. 栏目原则

LarkixMaker 的一级栏目保持 4 个，不随文章临时新增：

| 栏目 | categoryKey | 定位 | 不收录 |
|---|---|---|---|
| 模拟电子 | `analog` | 模拟前端、电源、滤波、运放、噪声、保护、测量 | 纯软件、纯产品新闻 |
| STM32 | `stm32` | STM32 外设、驱动、实时控制、调试、固件维护 | 与 STM32 无关的通用 C 教程 |
| ESP32 | `esp32` | 联网节点、低功耗、传感器、MQTT、OTA、本地存储 | 泛智能家居资讯 |
| 开源项目 | `projects` | 可复现的开源硬件项目文档、项目日志、BOM、固件、外壳 | 只有概念没有资料沉淀的项目介绍 |

## 2. 二级主题

二级主题用于选题规划、标签建议和未来专题页，不直接替代一级栏目。

| 一级栏目 | 二级主题 |
|---|---|
| 模拟电子 | `filter`、`op-amp`、`power`、`adc-front-end`、`noise`、`protection`、`measurement`、`simulation` |
| STM32 | `adc`、`dma`、`timer`、`uart`、`i2c`、`spi`、`rtos`、`bootloader`、`debug`、`calibration` |
| ESP32 | `low-power`、`wifi`、`mqtt`、`sensor-node`、`ota`、`storage`、`battery`、`home-automation` |
| 开源项目 | `audio`、`power-supply`、`measurement-tool`、`smart-home`、`firmware`、`mechanical`、`bom`、`pcb` |

## 3. 标签类型

每篇文章建议 4-8 个标签，项目建议 5-10 个标签。标签以逗号分隔，当前兼容格式：

```text
STM32,ADC,DMA,校准,调试,设计指南
```

| 标签类型 | 作用 | 示例 |
|---|---|---|
| 平台/芯片 | 说明硬件或平台对象 | `STM32`、`ESP32`、`ESP32-C3` |
| 技术对象 | 说明核心技术点 | `ADC`、`DMA`、`MQTT`、`Sallen-Key`、`GBW`、`OTA` |
| 工程环节 | 说明读者要完成的动作 | `调试`、`校准`、`低功耗`、`PCB布局`、`BOM` |
| 内容形态 | 管理读者预期 | `设计指南`、`原理解析`、`项目规划`、`踩坑记录`、`调试记录` |

## 4. 命名规则

| 规则 | 说明 |
|---|---|
| 专有缩写大写 | `ADC`、`DMA`、`MQTT`、`BOM`、`PCB`、`OTA` |
| 官方平台名优先 | 使用 `STM32`、`ESP32`，不写成 `stm32` 或 `esp 32` |
| 中文工程标签短而稳定 | 优先 `低功耗`，不要写 `怎么降低功耗` |
| 避免重复同义词 | `调试` 与 `故障排查` 二选一，默认用 `调试` |
| 避免泛标签 | 不使用 `技术`、`硬件`、`教程` 这类信息量低的标签 |
| 标签不写成句子 | 不使用 `适合新手学习ADC` 这类长句 |
