## 内容原则

1. 首页三条课程路径只承载学习方向，不替代现有 Hero。
2. 推荐内容优先使用当前已有文章与项目数据，缺口用“后续补位建议”记录，不在第一阶段强行伪造文章。
3. 分类页右侧资源区以“工具、关键词、相关项目”为主，帮助用户知道下一步该看什么、做什么。
4. `category=all` 不归属单一路线，应展示“全部教程”和“推荐学习路线”。

## 首页课程路径文案

### Analog / 模拟电子

标题：模拟电子
英文：Analog Electronics
摘要：从器件指标、运放反馈和滤波器开始，逐步建立可测量、可调试、可复现的模拟电路设计能力。
CTA：进入模拟电子路线
链接：`category.html?category=analog`

阶段：
- 基础指标
- 运放与反馈
- 滤波器设计
- ADC 前端
- 测量验证

推荐内容：
- `analog-active-filter`：有源低通滤波器设计与仿真分析
- `stm32-adc-dma-precision`：STM32 ADC 模拟采样从原理到精度优化
- `opensource-power-amplifier`：开源桌面功率放大器项目规划

后续补位建议：
- 运放输入偏置、电源轨与输出摆幅专题
- ADC 前端抗混叠滤波与采样保持专题

### STM32

标题：STM32
英文：STM32 Embedded Systems
摘要：围绕采样、定时、DMA、通信和调试，把 MCU 外设知识组织成可落地的嵌入式项目能力。
CTA：进入 STM32 路线
链接：`category.html?category=stm32`

阶段：
- 开发环境
- GPIO 与定时器
- ADC 与 DMA
- 通信接口
- 综合调试

推荐内容：
- `stm32-adc-dma-precision`：STM32 ADC 模拟采样从原理到精度优化
- `logic-analyzer`：GokottaLogic 逻辑分析仪
- `programmable-power`：可编程电源 0-30V/3A

后续补位建议：
- STM32 定时器触发 ADC 采样专题
- UART/I2C/SPI 调试链路专题

### ESP32

标题：ESP32
英文：ESP32 IoT Nodes
摘要：从联网、传感器节点、MQTT 和 OTA 入手，最终落到低功耗、可部署、可维护的 IoT 节点设计。
CTA：进入 ESP32 路线
链接：`category.html?category=esp32`

阶段：
- 联网基础
- 传感器节点
- MQTT 通信
- OTA 升级
- 低功耗部署

推荐内容：
- `esp32-low-power-node`：ESP32 低功耗智能家居节点设计指南
- `smart-home-hub`：ESP32 智能家居节点

后续补位建议：
- ESP32 Deep Sleep 电流测量专题
- MQTT 主题设计与离线重连专题
- OTA 灰度升级与回滚专题

### 全部教程资源区

区块标题：推荐学习路线
说明：如果还不确定方向，建议按“模拟输入 -> MCU 采样 -> IoT 部署”的顺序建立完整电子系统视角。

路线推荐：
- 模拟电子：适合先补电路基础、滤波器、测量与 ADC 前端。
- STM32：适合进入 MCU 外设、采样链路、DMA 和调试。
- ESP32：适合学习联网节点、MQTT、OTA 和低功耗部署。

方向筛选：
- 全部
- 模拟电子
- STM32
- ESP32

## SEO 与知识体系建议

首页课程路径区可使用标题“课程路径 / Learning Paths”，支持搜索引擎理解网站不是单篇文章列表，而是电子技术学习体系。

分类页建议保留中文分类标题，并补充英文副标题：
- 模拟电子 / Analog Electronics
- STM32 / STM32 Embedded Systems
- ESP32 / ESP32 IoT Nodes
- 全部教程 / All Lessons

推荐的内部链接关系：
- 模拟电子文章可链接到 STM32 ADC 文章，形成“模拟前端 -> 数字采样”的桥接。
- STM32 ADC 文章可链接到逻辑分析仪与可编程电源项目，形成“调试工具 -> 系统项目”的桥接。
- ESP32 文章可链接到智能家居节点项目，形成“教程 -> 项目复现”的桥接。

## 给 Agent4 的接入边界

1. 可新增前端静态 `courseMeta`，但第一阶段不要改数据库。
2. `recommendedPosts` 中既包含文章 id，也包含项目 id 时，渲染层需要按现有 `posts/projects` 数据源分别查找；找不到时静默跳过。
3. 分类页三栏布局只改变信息组织，不删除原文章列表、项目链接、封面、日期、阅读时长。
4. 首页顺序建议：Hero -> Course Paths -> Miniapp Tools -> Recent Lessons -> Open Projects。
5. `all` 分类页右侧使用“推荐学习路线”，不要展示某一个方向的资源区。
6. 不修改 `server.js`、SQLite schema、Hero 背景轮播与 Hero 卡片逻辑。
