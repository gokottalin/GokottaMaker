## 2. 轮播定位

首页轮播不是“推荐位数量更多的文章列表”，而是网站首屏的 4 张名片。它必须回答：

1. LarkixMaker 现在最值得读什么。
2. 这个站长期沉淀哪些技术方向。
3. 访客第一次打开首页时，能不能立刻理解站点价值。

因此，轮播内容要稳定、代表性强、可继续内链，不应频繁追随临时草稿或低完成度内容。

## 3. 四槽位运营职责

| 槽位 | 名称 | 推荐内容 | 运营意义 | 更新频率 |
|---:|---|---|---|---|
| Slot 0 | 首屏主打 | 当前最重要的核心教程、阶段性代表项目、站点主线内容 | 首页第一眼，必须最能代表网站价值 | 1-2 周复核 |
| Slot 1 | 嵌入式工程 | STM32 或 ESP32 中最有工程价值的教程 | 强化嵌入式读者入口 | 2-4 周复核 |
| Slot 2 | 电子基础能力 | 模拟电子、电源、测量、ADC 前端等基础文章 | 建立硬件工程可信度 | 4 周复核 |
| Slot 3 | 长期项目 | 开源项目、项目日志、可复现资料页 | 引导访客进入项目体系 | 4-8 周复核 |

## 4. 准入标准

内容进入首页轮播前必须同时满足：

| 检查项 | 标准 |
|---|---|
| 发布状态 | 文章必须已发布；项目建议已上线，规划中项目只能放 Slot 3 且必须有清晰项目规划 |
| 标题 | 能说明技术对象和收益点，不使用空泛标题 |
| 摘要 | 40-90 个中文字符，能独立说明内容价值 |
| 封面 | 与内容主题相关，移动端裁切后仍可识别 |
| Markdown | 至少有 4 个二级标题，技术文章需包含常见问题或扩展阅读 |
| 标签 | 至少 4 个受控标签，能支持相关内容推荐 |
| 内链 | 至少有 1 个前置/后续内容或相关项目可连接 |
| 时效 | 内容不过期，或已说明版本/适用环境 |

## 5. 禁止进入轮播的内容

以下内容不应进入首页轮播：

- 草稿、回收站内容。
- 只有标题和摘要、正文空洞的占位内容。
- 封面缺失、封面与主题明显不匹配的内容。
- 未解释适用边界的实验性结论。
- 项目状态不清楚、没有 BOM/原理图/PCB/固件/调试记录入口的项目。
- 纯公告、纯版本记录、纯管理说明。
- 与当前 4 个主方向无关的内容。
- 过度重复同一主题，导致四个槽位都指向同一技术点。

## 6. 选择评分模型

当多个内容都适合轮播时，用 100 分制排序。

| 维度 | 权重 | 说明 |
|---|---:|---|
| 技术代表性 | 30 | 是否代表模拟电子、STM32、ESP32、开源项目的核心能力 |
| 工程可复用性 | 25 | 读者是否能直接复用方法、流程、参数或检查清单 |
| 内容完整度 | 20 | 标题、摘要、封面、标签、正文结构、常见问题是否完整 |
| 内链价值 | 15 | 是否能连接现有文章、项目或后续路线图 |
| 新鲜度 | 10 | 是否是近期重点内容或近期有更新 |

推荐门槛：

| 分数 | 处理 |
|---:|---|
| 90-100 | 可进入 Slot 0 或当前最重要槽位 |
| 80-89 | 可进入 Slot 1-3 |
| 70-79 | 可作为候选，先补摘要、标签、封面或内链 |
| 70 以下 | 暂不进入轮播 |

## 7. 槽位选择细则

### Slot 0：首屏主打

优先选择：

- 当前阶段最希望新访客阅读的核心教程。
- 能代表网站定位的跨方向内容，例如“ADC 前端 + STM32 采样链路”。
- 已经完成度高、摘要清晰、封面表现好的项目文档。

不建议：

- 过窄的单点技巧。
- 只有项目规划但资料不完整的项目。
- 标题过长导致移动端首屏压迫的内容。

### Slot 1：嵌入式工程

优先选择：

- STM32 ADC、DMA、定时器、通信接口、Bootloader 等工程教程。
- ESP32 Deep Sleep、MQTT、OTA、电池检测等联网节点教程。
- 有代码片段和调试建议的文章。

轮换原则：

- STM32 和 ESP32 不必强行各占一个槽，但连续两期不应完全缺席其中一类。

### Slot 2：电子基础能力

优先选择：

- 模拟电子、ADC 前端、滤波器、电源纹波、输入保护、测量方法。
- 能支撑其他文章的“前置知识”。

运营意义：

- 让首页不只像 MCU 博客，也体现硬件工程基础。

### Slot 3：长期项目

优先选择：

- 已上线项目详情。
- 正在开发但文档结构完整的开源项目。
- 有明确下一步、BOM/PCB/固件/调试记录入口的项目。

规划中项目准入：

- 只能放 Slot 3。
- 必须有项目状态、设计目标、系统结构、资料开放计划。
- 按钮应引导到项目概述，而不是空详情。

## 8. 当前内容推荐基线

按当前种子内容，建议默认槽位：

| 槽位 | 推荐内容 | 理由 |
|---:|---|---|
| 0 | STM32 ADC 模拟采样从原理到精度优化 | 代表嵌入式和模拟采样主线，工程价值最高 |
| 1 | ESP32 低功耗智能家居节点设计指南 | 覆盖联网、低功耗和项目化方向 |
| 2 | 有源低通滤波器设计与仿真分析 | 作为模拟电子基础能力入口 |
| 3 | 开源桌面功率放大器项目规划 | 展示开源硬件长期项目方向 |

如果新增第一批路线图内容，建议优先替换顺序：

| 新内容 | 推荐替换 |
|---|---|
| ADC 前端 RC 滤波与输入保护电路设计 | Slot 2 |
| STM32 ADC 采样时间如何影响高阻信号源精度 | Slot 1 或 Slot 0 |
| ESP32 Deep Sleep 实测功耗与唤醒策略 | Slot 1 |
| 开源硬件项目如何组织 BOM、原理图和调试记录 | Slot 3 |

## 9. 标题、摘要、封面规范

### 标题

首页轮播标题必须：

- 包含明确技术对象：如 `STM32 ADC`、`ESP32 Deep Sleep`、`Sallen-Key`。
- 包含收益点：如 `精度优化`、`低功耗`、`输入保护`。
- 不超过 32 个中文字符为佳。

不建议：

- “一些经验总结”
- “项目规划”
- “学习笔记”
- “技术分享”

### 摘要

摘要必须：

- 说明场景、方法和收益。
- 能在 Hero 中独立阅读。
- 不写“本文介绍了……”这种弱开头。

建议长度：

```text
40-90 个中文字符
```

### 封面

封面必须：

- 与内容主题强相关。
- 在 390px 手机视口裁切后仍有清晰主体。
- 避免纯装饰、纯氛围、与技术对象无关的图。
- 项目类封面优先展示真实项目、实验台、结构或关键模块。

## 10. 轮播更新流程

每次调整首页轮播，按以下流程：

1. 先在内容列表中确认候选内容已发布且不在回收站。
2. 按评分模型判断是否达到 80 分以上。
3. 判断应放入哪个槽位，而不是随便填空槽。
4. 检查是否造成四槽位主题失衡。
5. 在管理端 Slot 面板替换或取消旧内容。
6. 保存后打开首页检查 Hero 标题、摘要、封面和按钮。
7. 检查 RSS/Sitemap 是否仍有内容质量。

## 11. 四槽位平衡规则

常规情况下，4 个槽位建议覆盖：

```text
1 个主打内容
1 个 STM32/ESP32 工程内容
1 个模拟电子/测量基础内容
1 个开源项目/项目日志内容
```

允许短期例外：

- 新项目发布周：可放 2 个项目内容，但不超过 1 周。
- 系列教程发布周：可放 2 个同方向文章，但必须保留至少 1 个其他方向入口。
- 重大修订内容上线：可临时进入 Slot 0，但下一轮复核。

## 12. RSS 与 Sitemap 内容质量建议

轮播内容通常也是 RSS/Sitemap 中高价值页面，因此必须：

- `title` 和 `excerpt/summary` 能独立表达页面价值。
- `date/publishedAt` 不为空。
- `tags` 不为空。
- 项目页如未上线，不应被当作轮播详情入口。
- 轮播内容不应长期指向已过期版本或未完成草稿。

## 13. 管理端提示文案建议

Agent3 后续可在“首页轮播管理”旁增加短提示：

```text
首页轮播最多 4 个槽位。Slot 0 放当前主打内容，Slot 1 放嵌入式工程教程，Slot 2 放模拟电子/测量基础，Slot 3 放开源项目或长期项目。草稿、回收站、封面不清晰或内容不完整的条目不建议进入轮播。
```

保存前若内容不完整，可提示：

```text
该内容已被设为首页轮播，但摘要、标签、封面或正文结构不完整。建议补齐后再发布到轮播。
```

## 14. 每周运营复核

每周复核一次：

- Slot 0 是否仍是当前最重要内容。
- 4 个槽位是否覆盖至少 3 个方向。
- 是否有新发布内容比现有轮播更适合。
- 是否有旧内容摘要、封面、标签需要更新。
- 是否存在重复槽位、越界槽位或超过 4 条脏数据。

每月复核一次：

- 轮播是否支撑 3 个月内容路线图。
- 是否有项目文档达到可复现标准，适合替换 Slot 3。
- 是否需要围绕新专题建立内容系列。

## 15. 验收标准

运营规则落地后，首页轮播应满足：

- 管理端只有 4 个槽位，且每个槽位有明确运营意义。
- 访客首页 4 张卡片不是随机内容，而是构成站点知识地图。
- 新访客能从首屏理解：本站关注模拟电子、STM32、ESP32、开源硬件项目。
- 搜索/RSS/Sitemap 中的高价值内容与首页推荐一致。
- 后续 Agent 调整轮播 UI 或 API 时，不再破坏内容运营标准。
