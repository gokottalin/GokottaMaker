# Agent5 术语表与标签治理规则

生成时间：2026-05-06 13:35
项目版本：`V2.1.1+20260506-1205`

## 1. 治理目标

标签和术语的目标是帮助搜索、内链、专题页和读者理解内容结构。标签不能成为随手写的关键词堆。

## 2. 标签规则

每篇文章建议 4-8 个标签，项目建议 5-10 个标签。

必须遵守：

- 平台名保持官方大小写：`STM32`、`ESP32`。
- 技术缩写大写：`ADC`、`DMA`、`MQTT`、`BOM`、`PCB`、`OTA`。
- 中文工程标签保持短词：`低功耗`、`调试`、`校准`。
- 不使用泛标签：`技术`、`教程`、`硬件`。
- 不把标签写成句子。

## 3. 标签类型

| 类型 | 说明 | 示例 |
|---|---|---|
| platform | 平台/芯片 | `STM32`、`ESP32` |
| topic | 技术对象 | `ADC`、`DMA`、`MQTT`、`Sallen-Key` |
| workflow | 工程动作 | `调试`、`校准`、`PCB布局`、`输入保护` |
| format | 内容形态 | `设计指南`、`原理解析`、`复现指南`、`调试记录` |

## 4. 核心术语表

| 术语 | 推荐写法 | 说明 |
|---|---|---|
| ADC | `ADC` | 模数转换器，不写 `Adc` |
| DMA | `DMA` | 直接内存访问 |
| GPIO | `GPIO` | 通用输入输出 |
| MQTT | `MQTT` | 轻量消息协议 |
| OTA | `OTA` | 固件远程升级 |
| BOM | `BOM` | 物料清单 |
| PCB | `PCB` | 印刷电路板 |
| GBW | `GBW` | 运放增益带宽积 |
| Deep Sleep | `Deep Sleep` | ESP32 深度休眠，英文保留 |
| Sallen-Key | `Sallen-Key` | 滤波器拓扑，保留连字符 |
| Bootloader | `Bootloader` | 启动加载程序 |
| LittleFS | `LittleFS` | 文件系统专有名词 |
| NVS | `NVS` | ESP32 非易失存储 |
| Kelvin 连接 | `Kelvin 连接` | 电流采样走线方式 |

## 6. 新增标签流程

新增标签前检查：

1. 是否已有同义标签。
2. 是否能归入 platform/topic/workflow/format。
3. 是否至少预计用于 2 篇内容。
4. 是否需要同步分类页或专题页。

新增后需要更新：

- 本文受控标签池。
- CMS 标签建议。
- 未来正式 tags 表。
- 相关内容推荐规则。

## 7. 每月复核

每月复核一次：

- 标签是否出现重复写法。
- 是否有只使用一次的低价值标签。
- 是否需要新增专题标签。
- 是否有旧标签需要合并。
