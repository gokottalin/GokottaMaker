# Agent3 管理端布局批注修正交接

时间：2026-05-06 07:48
版本：V2.0.0+20260506-0748

## 本轮管理端变更

- 登录页两侧动画改为芯片卡通形象：左侧 SOP-8，右侧 ESP32。
- 密码输入时继续触发闭眼/遮挡状态。
- 管理端主导航由左侧边栏改为顶部导航。
- 导航重新分组为：
  - 内容工作台：内容编辑、内容列表
  - 系统与访问：系统状态、访客首页
- 内容编辑器不再作为底部悬浮 Dock 使用。
- 编辑器恢复为页面内双栏布局，左侧表单，右侧预览。
- 预览面板位于内容流中，桌面端 sticky，方便边写边看。

## 兼容要求

- 后续不要把 `.editor-dock` 改回 `position: fixed`。
- 后续不要重新启用底部 Dock handle 作为主入口。
- 可以继续保留自动草稿、图片库、批量内容管理等功能。
- 如果新增管理栏目，优先扩展 `.nav-group`，不要恢复左侧栏。
- JS 中旧的 sidebar/dock 状态逻辑暂时保留兼容旧 localStorage，后续可单独清理。

## 风险提示

- 管理端 CSS 仍沿用 `.editor-dock` 命名，但现在语义已经变为页面内编辑区。后续重构时可以重命名为 `.editor-workspace`。
- 当前芯片角色由 CSS 伪元素实现，适合轻量原型；如后续追求更强表现，可交给视觉资产任务升级为图片。
