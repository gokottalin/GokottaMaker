## 2. 兼容项

当前 `admin/admin.js` 已兼容后端返回的 `csrfToken`：

- `GET /api/session` 返回 token 时保存。
- `POST /api/login` 返回 token 时保存。
- 非 GET/HEAD/OPTIONS 请求自动附加 `X-CSRF-Token`。

这与当前工作区里 `server.js` 的 CSRF 防护逻辑兼容。若后端未返回 token，前端不会附加空 token，不影响旧接口。
