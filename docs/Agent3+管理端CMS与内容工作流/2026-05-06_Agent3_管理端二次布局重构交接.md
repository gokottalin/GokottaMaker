# Agent3 管理端二次布局重构交接

时间：2026-05-06 09:13  
版本：V2.1.0+20260506-0913

## 上次 V2.0.0 变更回顾

- 管理端从左侧栏改为顶部导航。
- 编辑器从底部 Dock 改为页面内双栏。
- 预览区回到内容流中。
- 登录动画改为 SOP-8 与 ESP32 芯片形象。

## 本次 V2.1.0 修正

- 页面内双栏仍然不符合用户预期，已改为：
  - 主页面显示预览。
  - 右侧固定浮窗显示编辑表单。
- 内容列表和系统状态不再堆叠在编辑页下方。
- 通过 hash 视图切换：
  - `#editor`
  - `#library`
  - `#health`
- 编辑页底部只保留少量“最近编辑内容”推荐。
- 内容列表页继续保留完整搜索、筛选、批量操作。
- 系统状态页进入时自动刷新。
- 修复 `admin/admin.js` 中中文文案编码损坏导致的语法问题。

## 后续开发边界

- 不要恢复底部 Dock 作为主编辑方式。
- 不要把完整内容列表放回编辑页下方。
- 不要把系统状态放回编辑页下方。
- 编辑浮窗可以优化最小化/展开，但默认必须足够大，不能变成狭窄工具条。
- 如果以后拆页面，优先拆成 `/admin/library.html` 和 `/admin/health.html`，保持当前视图逻辑兼容。
