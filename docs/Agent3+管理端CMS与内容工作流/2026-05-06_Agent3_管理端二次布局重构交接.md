# Agent3 管理端二次布局重构交接

时间：2026-05-06 12:05
版本：V2.1.1+20260506-1205
责任方向：管理端 CMS、内容工作流、数据读写、上传与表单交互

## 上次 V2.0.0 变更回顾

- 管理端从左侧栏改为顶部导航，并按“内容工作台”和“系统与访问”重新分组。
- 登录页动画改为 SOP-8、STM32、ESP32 芯片卡通方向。
- 预览区从悬浮窗回到页面内容流中，避免遮挡编辑。
- 内容列表、系统状态从编辑区下方拆出为独立管理视图。

## V2.1.0 变更回顾

- 编辑页改为“主页面预览 + 右侧固定编辑浮窗”。
- `#editor` 只负责内容编辑、网页预览、少量最近内容推荐。
- `#library` 只负责完整内容列表、筛选、批量发布、批量回收、恢复。
- `#health` 只负责系统状态、数据库、上传目录、备份信息。
- 通过 `data-admin-view` 和 URL hash 控制视图切换：
  - `#editor`
  - `#library`
  - `#health`
- 修复了上一轮 `admin/admin.js` 中因中文编码损坏导致的语法风险。

## 本次 V2.1.1 变更

- 最近编辑内容卡片新增封面图显示。
- 数据来源优先级：
  1. `item.cover`
  2. 项目默认 `./assets/covers/project-cover.png`
  3. 文章按分类兜底到 `analog-cover`、`stm32-cover`、`esp32-cover` 或 `project-cover`
- 新增 `fallbackCover(item)`，供管理端推荐卡片复用。
- 最近编辑卡片 HTML 结构变为：
  - `<img>`：封面缩略图
  - `.admin-recommendation-body`：类型、标题、日期、编辑按钮
- 右侧编辑浮窗、主预览区、独立内容列表和系统状态视图不改变。

## 后续开发边界

- 不要把完整内容列表放回编辑页下方。
- 不要把系统状态放回编辑页下方。
- 最近编辑区只显示少量推荐内容，作为快速入口，不承担完整管理功能。
- 编辑浮窗可以继续优化最小化/展开，但默认必须保证足够宽度和可编辑性。
- 如果后续拆成独立页面，优先拆为 `/admin/library.html` 与 `/admin/health.html`，同时保留当前 hash 视图兼容。

## Agent3 输入输出接口

- 输入：
  - `serverContent.posts`
  - `serverContent.projects`
  - 上传接口返回的 `uploads`
  - `item.cover`、`item.category`、`item.contentType`、`item.status`
- 输出：
  - 管理端表单 payload
  - 最近编辑推荐卡片
  - 内容列表筛选结果
  - 系统状态卡片
- 与 Agent4 的交界：
  - Agent3 负责数据字段、渲染结构、交互流程。
  - Agent4 负责视觉样式、卡片比例、响应式体验。
