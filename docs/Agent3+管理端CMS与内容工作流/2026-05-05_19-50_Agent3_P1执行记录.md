## 4. 风险与注意

1. 批量发布/转草稿会通过保存接口更新内容，因此会刷新 `updated_at`，这符合“内容被批量变更”的语义。
2. 批量发布作用于回收站内容时，保存接口可能会将其从回收站恢复；若产品语义不希望这样，后续应限制批量发布只作用于非回收站内容。
3. 前端顺序批量操作不是事务；网络中断时可能出现部分成功。当前会保留最新返回结果并显示错误，后续应由后端事务型 API 补齐。
4. 图片路径复制依赖浏览器剪贴板权限；失败时不影响选择封面。
