## decisions

- 待决事项是一条 CMS 工作流记录，不是公开内容，也不改变待决期间的文章渲染。
- 决策粒度固定为单篇文章、单个稳定 `bindingId`，不提供隐式升级或批量升级。
- “保留旧修订”只关闭事项，不改写正文或绑定。
- “采用最新修订”保留 `bindingId`，显式替换正文中的公式卡与不可变修订身份。
- “另建公式卡”从旧修订 LaTeX 开始，由作者补齐语义元数据，再在单一事务中建卡并重新绑定。
- 元数据变更与 LaTeX 变更严格分离；前者不制造版本噪声。
- 后续新修订取代旧待决目标，但不删除审计历史。

## risks

- 归档公式卡的既有文章继续内联渲染旧修订，但归档卡独立访客页按 A14 既有规则保持隐藏；本轮未改变该边界。
- 采用或另建卡会更新文章保存的内部公式短码；CMS 因此禁止在文章有未保存本地编辑时处理事项。
- 当前没有跨文章批量决策，也没有自动采用策略；这是明确的安全边界，不是遗漏。
- 浏览器烟测实际提交覆盖另建卡；保留与采用的数据库/API 结果由隔离集成测试覆盖，CMS 三个入口和窄屏布局由浏览器覆盖。
