## decisions

- 自检不读取 `.env`，直接为单次子进程注入随机测试凭据和 48 字节 URL-safe private CMS segment。
- `DATA_DIR` 位于 Windows `%TEMP%/larkix-clean-clone-<pid>-<guid>/data`，并以路径前缀和目录名双重校验限制删除范围。
- 启动检查结束后先停止测试服务，再清除 private gateway 环境，避免污染各回归脚本自行建立的旧回环 API 测试夹具。
- 默认执行 `npm ci --ignore-scripts`；`-SkipInstall` 仅供同一锁文件依赖已安装后的快速复验。
- Windows 自检不模拟 systemd、Nginx、TLS、持久 `/srv` 数据和生产密钥；这些仍属于 Owner 明确授权的 Linux 部署任务。
