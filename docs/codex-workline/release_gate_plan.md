```bash
  HEALTH_URL=http://127.0.0.1:4173/healthz \
  bash scripts/rollback.sh <PRE_DEPLOY_COMMIT>
```

该命令会先备份、执行 `git reset --hard`、重启服务并访问 health；它是破坏性
生产操作，本轮没有执行。代码 rollback 不会替换 SQLite 或 uploads。数据
restore 必须另行获得明确授权，先重复 dry-run，再执行正式 restore；不得把
代码 rollback 与数据恢复合并成自动动作。
