# 公式地图横向流程布局

## 目标

我将公式地图按 `来源公式 -> 依赖公式` 的方向从左向右展开。布局只读取既有 DAG、修订与可见性投影，不改变关系语义，也不保存第二份关系数据。

## 布局与节点

- 我按全量可见分量执行稳定拓扑排序，以根节点深度为 0，并用最长来源路径确定每个依赖节点的深度。同层节点按既有 `rank`、显示名称和节点 ID 稳定排序。
- 我先调用共享 `LarkixMath.render(..., { displayMode: true })` 生成 KaTeX，再用 `getBoundingClientRect()` 测量节点 DOM。横向列宽取本层最大实测宽度，纵向间距按各节点实测高度累加。
- 节点公式保持 `max-content` 与单行数学排版。长公式、根号和嵌套分式扩大节点边界，不截断、不省略，也不压缩到固定卡片宽度。
- Cytoscape 节点使用相同的实测宽高作为透明几何锚点，因此连接线从来源节点右侧指向依赖节点左侧；KaTeX DOM 覆盖层随画布平移、缩放和节点位置同步。
- 地图节点本身承担导航。节点内不生成正文公式绑定标记，也不复制紫色返回图标。

## 视口与交互

- 初始视口在 `48%` 到 `100%` 的可读范围内适配。超宽图谱不被强制压缩；当完整适配会低于可读下限时，视口改为居中当前公式，用户继续平移浏览。
- 鼠标滚轮平移画布，`Ctrl`/`Command` 加滚轮缩放；触控支持单指平移与双指缩放。
- 工具栏提供放大、缩小、适配、居中当前公式、展开所选分支和收起旁支。画布获得焦点后可用方向键平移，`+`/`-` 缩放，`0` 适配，`Home` 居中当前公式。
- 节点可拖动调整局部位置。拖动超过阈值时不触发跳转；普通点击在游客页进入对应公式，在 CMS 中只选择节点。
- 当前公式、所选节点、草稿与归档状态使用独立边框语义；明暗主题和键盘焦点均保持可辨识。

## 边界

- 图谱仍使用服务端提供的公开或 CMS 节点集合，因此草稿、待发布和归档边界保持不变。
- 展开操作只把已在载荷中的相邻节点加入当前视图；服务端载荷上限与截断标记保持不变。
- 无效公式只显示安全占位，不回显原始 LaTeX。
- 本实现不修改 API、数据库、CMS HTML/JavaScript、包文件或受保护样式。

## 验证

专项命令：

```powershell
node scripts/test-formula-map-flow-layout.js
```

专项覆盖分支、汇合、长公式、嵌套分式和深路径，并在无项目服务的本机无头浏览器中检查桌面与 390 px 移动视口的 DOM 实测、边方向、非空画布像素、公式溢出、滚轮/触控平移、工具栏/双指缩放、鼠标/触控拖拽、点击导航、暗色主题与无障碍契约。
