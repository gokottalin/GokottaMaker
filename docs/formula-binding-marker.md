# 公式绑定右上角标记

文章和推导正文使用同一套公式绑定表现：作者原公式保持原位，绑定只增加一个紫色圆形 `↩` 标记。标记位于公式右上角，悬停或键盘聚焦可读取目标公式名称，点击进入稳定公式卡与详细推导页面。

## 作者协议

行内公式把绑定短码紧跟在完整公式后：

```md
$D=1-\frac{V_{in}}{V_{out}}$ {{formula:bind.d|formula.boost-duty|rev.1|inline}}
```

块级公式把绑定短码放在完整公式块下一行：

```md
$$
\Delta I_L=\frac{V_{in}D}{Lf_s}
$$
{{formula:bind.ripple|formula.boost-ripple|rev.1|display}}
```

渲染器仅用短码解析目标身份，不用数据库 LaTeX 替换或重复作者公式。没有有效绑定、目标不可公开或普通未绑定公式均不显示标记。公式地图保持节点自身点击行为，不使用正文标记。

为兼容既有文章，历史上独立存在的 `{{formula:...}}` 仍按旧协议显示一次公式正文和同一跳转标记；新的 CMS 选择创建流程必须保存作者原公式并追加短码。

## 布局与可访问性

- 行内标记使用相对位移形成上标效果，不另起文字链接行。
- 块级标记绝对定位在公式容器右上角，不改变公式边界和居中。
- 标记使用原生链接、`title` 与 `aria-label`，支持键盘、触控和悬停。
- 紫色样式集中在 `styles/26-inline-math.css`，同时提供深色主题和焦点环。
