## 3. 生产配置建议

服务器 `/etc/gokottamaker.env` 建议增加：

```text
BACKUP_ROOT=/srv/gokottamaker-backups
```

如果不设置，程序默认使用 `/srv/gokottamaker-backups`。

## 4. 验证建议

本地验证：

```powershell
node --experimental-sqlite --check server.js
node --experimental-sqlite server.js
curl http://127.0.0.1:4173/healthz
```

线上验证：

```bash
curl -fsS http://127.0.0.1:4173/healthz
curl -fsS http://127.0.0.1:4173/api/admin/health
```

注意：`/api/admin/health` 是管理员接口，生产环境需要登录态 Cookie，或通过管理端健康面板查看。
