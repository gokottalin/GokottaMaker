## 2. 本地限制

本地 Git Bash 环境刻意使用 `PATH=/usr/bin:/bin`，避开 Windows/Android SDK 的 `sqlite3.exe` 路径兼容问题，因此本次验证的是“无 sqlite3 时的降级备份 + checksum + dry-run 校验链路”。

生产服务器 Ubuntu 环境应安装 `sqlite3` 后再做正式演练，这样备份会走 SQLite `.backup` 一致性快照，并执行 `PRAGMA integrity_check`。
