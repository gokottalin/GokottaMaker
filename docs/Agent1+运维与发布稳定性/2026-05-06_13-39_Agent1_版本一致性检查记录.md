## 3. 规则

站点版本以 `server.js` 为服务端运行来源：

```text
siteVersion = V主版本.次版本.补丁版本
siteBuild = YYYYMMDD-HHmm
versionLabel = siteVersion + "+" + siteBuild
```

`package.json` 使用 SemVer，不带 `V` 和 build，例如：

```text
2.1.1
```

HTML 静态资源版本参数必须与 `siteBuild` 一致。
