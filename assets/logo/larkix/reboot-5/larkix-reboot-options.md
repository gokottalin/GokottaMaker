# Larkix LOGO Reboot Options

本轮为重新探索方案，供 5 选 1。

| 编号 | 名称 | 方向 |
|---|---|---|
| 01 | 流线飞鸟 | 更接近现代科技品牌，轮廓饱满，适合继续做主 LOGO |
| 02 | 圆标负形 | 适合头像、App icon、社交媒体和 favicon |
| 03 | 线性羽翼 | 极简、轻盈，适合工具栏和小尺寸 UI |
| 04 | 展开双翼 | 更像准备起飞，徽章感和象征性更强 |
| 05 | 锐翼光切 | 更锐利、有速度感，适合工程工具品牌 |
