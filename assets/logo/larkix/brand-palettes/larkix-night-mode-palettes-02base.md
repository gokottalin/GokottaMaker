# Larkix Night Mode Palette Options

白天模式已选择 `02 晨光淡紫`。以下为对应黑夜模式候选。

## 01 夜幕淡紫

```css
[data-theme="dark"] {
  --larkix-bg: #0B0712;
  --larkix-surface: #120A1F;
  --larkix-panel: #1B102B;
  --larkix-primary: #A78BFA;
  --larkix-primary-deep: #7C3AED;
  --larkix-accent: #F59E0B;
  --larkix-text: #F8FAFC;
  --larkix-muted: #B6A8C9;
  --larkix-border: #2A1740;
}
```
